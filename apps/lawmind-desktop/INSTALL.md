# LawMind 安装说明（终端用户）

面向「下载压缩包 / 安装包即用」的律师工作台。**无需单独安装 Node.js 或 officecli**：安装包内已附带运行本地服务所需的 Node 运行时，以及 Word 修订痕迹 / 改稿所用的 OfficeCLI。

> 图文版（含每一步的真实界面截图，可直接转发给律师）：[docs/install-guide.md](./docs/install-guide.md)。

## 我该下载哪一个？

在发布页（或供应商提供的网盘）按自己的电脑选择 **对应系统、对应架构** 的文件。文件名形如：

`LawMind-<版本>-<系统>-<架构>.<扩展名>`

| 系统 | 常见文件 | 使用方式 |
|------|----------|----------|
| **Windows（64 位）** | `.exe`（安装向导）、`…-portable.exe`（绿色版）、`.zip`（解压文件夹） | 双击安装或解压后运行其中的 `LawMind.exe`。可选：将 zip 解压到固定目录后建桌面快捷方式。 |
| **macOS（Apple 芯片）** | `LawMind-<版本>-mac-arm64.dmg` 或 `.zip` | M1/M2/M3/M4 选这个。**dmg**：双击 → 把 `LawMind` 拖进「应用程序」。已公证的正式包可直接双击；未签名的包首次放行步骤见下节「未签名包怎么放行」。 |
| **macOS（Intel）** | `LawMind-<版本>-mac-x64.dmg` 或 `.zip` | Intel 芯片选这个（文件名里是 `x64`）。用法同上。 |
| **Linux（x86_64）** | `.AppImage` 或 `.tar.gz` | **AppImage**：`chmod +x LawMind-*.AppImage` 后双击或终端运行。**tar.gz**：解压到目录后运行其中的可执行文件（名称以包内为准）。 |

> **架构不匹配**会导致无法运行，请与「关于本机 → 芯片 / 系统信息」中的处理器架构一致：Apple 芯片 = `arm64`，Intel = `x64`。
>
> 内测/正式包应做到「双击就能开」（Developer ID 签名 + 公证）。如果你的 Mac 提示「已损坏，无法打开」，说明拿到的是未签名的测试包——请按下面「未签名包怎么放行」处理，并告知发布者。

## 未签名包怎么放行（macOS）

没有 Apple Developer ID 证书时打的包是 **adhoc 签名、未公证**的。macOS 只放行「已用 Developer ID 签名并公证」的下载包，所以首次打开会被 Gatekeeper 拦一次。**拦一次之后系统会记住这个例外，以后双击就能开。**

**步骤**（macOS 15 Sequoia 及更新版本）：

1. 双击 dmg，把 `LawMind` 拖进「应用程序」。
2. 双击 `LawMind`。会弹「Apple 无法验证 “LawMind” 是否包含可能危害 Mac 的恶意软件」，点 **完成**（这个对话框里没有「打开」按钮，是正常的）。
3. 打开 **系统设置 → 隐私与安全性**，往下滚到「安全性」区域，会看到「已阻止使用 “LawMind”，因为无法验证开发者」。
4. 点 **仍要打开**，按提示输入登录密码或 Touch ID，再在确认框点 **打开**。
5. 程序随即启动。之后正常双击即可，不需要重复放行。

**macOS 14 Sonoma 及更早版本**：右键（或 Control + 点按）`LawMind` → **打开** → 在弹窗里再点 **打开**。系统设置里的「仍要打开」路径同样可用。

**如果提示「已损坏，无法打开，你应该将它移到废纸篓」**：文件没有损坏，是未签名包被加了隔离标记。打开「终端」执行一次：

```bash
xattr -dr com.apple.quarantine /Applications/LawMind.app
```

再去启动即可。多个用户批量部署时，可以把这条命令写成一段脚本随安装说明一起发。

**绕开这一步的办法**：Gatekeeper 只在文件带「来自网络的隔离标记」时生效。用 U 盘、内网共享盘等渠道拷贝给同事，通常不带该标记，双击即可运行——但正式对外分发仍应签名并公证。

**自签名证书（自己用「钥匙串访问」生成的证书）不管用**：Gatekeeper 只认 Apple 签发的 Developer ID Application 证书，且必须完成公证。要让用户真的「双击即装」，需要 Apple Developer Program（个人/公司每年 99 美元）导出证书后，用 `CSC_LINK` / `CSC_NAME` 加公证凭据重新打包。

## 更新 LawMind

- **应用内更新（打包版）**：联网时应用会在后台检查新版本；也可在菜单 **帮助 → 检查更新** 或 **设置** 底部「应用更新」中手动检查。依赖与正式安装包相同的 **GitHub Release**（见开发者文档中的 `latest*.yml` 说明）。
- **手动下载**：菜单 **帮助 → 下载安装包** 或浏览器打开「下载落地页」，按系统下载对应压缩包或安装程序后覆盖安装即可。

## 首次打开以后要做什么？

1. **开箱即用**：安装包已内置一份 DeepSeek 凭据，首次打开可以直接对话，不需要先申请 Key。若要换成你自己的 Key（例如走律所统一采购的账号、或内置额度用尽），打开 **设置 → 模型与连接**，粘贴自己的 Key 保存即可——你自己的配置**始终优先于**内置凭据，且只存在本机。
2. 要用北大法宝查法规和案例：打开 **设置 → 模型与连接**，在「连接权威库」粘贴你自己的访问令牌并保存。不填则使用国家法律法规数据库的公开检索。
3. 在 **设置** 中可 **创建多个智能体**（不同分工）；需要多步衔接时可在 **在办 → 按流程办** 中配置后台工作流。
4. **对外文书、材料交付**：请在 **在办签批 / 改稿** 中完成律师把关与门禁后再渲染或对外发出。

> **内置凭据的边界**：它是随安装包分发的共享 Key，拿到安装包的人都能解出包里同一份文件，因此**不要把它当作保密信息**。它只用于「先跑起来」；正式办案、涉密材料、或需要独立计费的场景，请换成自己的 Key。轮换方法见 [README.md](./README.md) 的「内置模型凭据」。

## 常见问题

- **macOS 提示「LawMind 想要使用钥匙串」**：这是系统在保护本机的 API Key。输入登录密码并点 **允许**（或「始终允许」）即可；拒绝也能用，只是每次重启要重新读取或重新填写 Key。升级到新版本后如果再次弹出，说明这一版没有做 Developer ID 签名——正式分发请让发布者签名并公证。
- **防火墙 / 安全软件**：本地服务仅监听 **127.0.0.1**；若被拦截，请按单位 IT 策略允许。
- **模型报错或 502**：检查 API Key、网络及模型服务商状态；应用内会尽量展示服务端返回的具体原因。

## 企业批量部署（IT）

- **macOS**：广泛分发建议 **代码签名 + 公证**；内嵌 Node 与 OfficeCLI 需符合安全策略。
- **Windows**：建议 **Authenticode 签名** 以减少 SmartScreen 提示。
- 供应链：仓库侧可生成 SBOM（根目录 `pnpm lawmind:sbom`、`pnpm lawmind:sbom:cyclonedx`）。
