## 典型首日路径

1. 安装桌面版，完成本机工作区与模型配置。
2. 打开一份合同，走审查 → 改稿 → 签批 → 导出。
3. 需要定时或邮件触发时，在「自动办件」处理结果并拍板。

详见 [律师快速指南](/LAWMIND-LAWYER-QUICKSTART) 与 [完整使用手册（归档）](/archive/LAWMIND-USER-MANUAL)。
