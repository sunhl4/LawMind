# LawMind 律师快速指南

> 写给执业律师的上手指南，不讲技术。读完你能：装好 LawMind、办完第一个案件、知道系统替你记住了什么、以及数据放在哪。  
> 产品口径见仓库根 `GOALS.md`（三条铁律）与 `docs/LAWMIND-DELIVERY.md`（交付与安装）；用词规范见 `docs/LAWMIND-TERMINOLOGY.md`。

## 一、LawMind 是什么

LawMind 是装在你自己电脑上的律师工作台。你把事**交办**给它——审一份合同、写一封律师函、整理一摞材料——它按流程去做，做完交给你**审核**，你**签批**之后才算数。

三条铁律（也是你验收我们的标准）：

1. **上手简单**：默认路径就能把事办下去，不需要先学配置。
2. **交付结果质量高**：交上来的稿子可审、可用、可担责，来源能核对。
3. **交付结果稳定性高**：同样交办的事，结果不飘；失败了能说清为什么。

一条底线：**对外的东西永远由你拍板**。系统可以起草、可以建议，但发送邮件、对外文书这类动作，永远停在你签批之前。LawMind 不构成法律意见，重要交付请你通篇审核。

## 二、安装与第一次打开

1. 安装桌面版（macOS 为 dmg 或 zip，Windows 为安装包或绿色版），双击打开即可，不需要额外装别的软件。
2. 第一次打开会出现**首跑向导**，共四步：
   - **身份**：选你的执业方向（如合同纠纷、劳动争议等），系统据此安排合适的助手与文书类型。
   - **偏好**：可一键「用推荐默认，跳过习惯」，以后随时在设置里补。
   - **文书**：选你最常交付的文书类型（如合同、函件）。
   - **开始**：系统自动建好第一个案件，并备好一句可以直接发出的交办指令。
3. 模型钥匙：LawMind 调用的大模型由你（或律所）自备账号。首次使用按向导提示填入即可；钥匙只存在你自己电脑上（见第六节）。

## 三、第一个案件：从交办到交付

主路径只有五步，对应界面上的同一个闭环：

1. **交办**：在「对话」里用大白话说要办的事，例如「帮我审查这份租赁合同，重点看押金和违约责任」，并把材料拖进去。材料不齐时系统会问你，问清楚才动手。
2. **对话跟进**：干活过程中你可以在对话里补充要求、纠正方向；系统会把进展和中间结果放在对话里。
3. **审核**：初稿出来后进入「审核」。你能看到正文、依据来源（点来源可回看原文段落）、以及一份「必核清单」——签批前要逐项确认的事项。
4. **改稿**：要改动就到「改稿」工作面。可以让助手按你的意见改，也可以自己改；每一版改动都留痕，可对比、可回退。
5. **签批与交付**：确认无误后点「签批」，再导出 Word 成品交付。未签批的稿子不会被当成终稿，更不会被发出去。导出时还可勾选「导出来源批注」，把每段文字的来源以 Word 批注形式交给客户备查。

日常打开 LawMind，先看顶栏 **工作台**：今天的手写计划、待回复邮件、开庭和期限都在这里勾完。合同还是诉讼用门类筛选；传票或法院短信贴进去，确认后才写入期限，需要时可导出日历文件。出稿仍回到「对话」交办；要拍板去「在办」。你自己的审查口径和案由词表在「设置 → 工作区」。

文书里的每段文字都带有来源：来自哪份材料、AI 建议、律师修改或导出，在「改稿」工作面点段落旁的「来源」即可查看。

## 四、「待我拍板」怎么用

「待我拍板」是**唯一**需要你决定的入口，集中在侧栏。里面只有三类事：

- **待签批**：稿子做好了，等你最终批准。
- **待补充**：系统缺信息（比如缺一份材料、缺一个日期），补上后它继续干。
- **待批准**：系统想做一件需要你授权的事（比如执行某个流程、向外发信），你点头它才做。

处理完一条少一条；没有积压时，这个入口是空的。你不需要去别处找「还有什么要我定的」。

## 五、记忆与偏好

- 系统会记住你的**偏好与习惯**（如常用的定金比例写法、惯用的落款格式）和**案件事实**（如某案的当事人、关键日期）。
- **不确认不写入**：系统觉得值得记住时，会放进「待确认」队列，你点头才真正记住；它不会悄悄改写你的档案。
- 你可以随时在设置里查看记忆来源、逐条修改或删除；改稿时接受的红线修改，也会作为你的习惯沉淀下来（同样经你确认）。
- 换电脑或重装不会自动带走记忆——记忆随工作区存在你自己的磁盘上（见第六节备份）。

## 六、数据安全常见问题（律师语言版）

**问：我的案件材料会上传到哪里？**  
不会上传。材料、草稿、记录都在你自己电脑的本地工作区里。唯一离开电脑的内容，是发给「你自己配置的」大模型接口的问答内容——用谁的模型、什么钥匙，由你决定。

**问：模型钥匙（API Key）放在哪？**  
放在你自己电脑的系统钥匙串或本机配置里，不写进案件文件，不随备份打包（除非你显式要求，且强烈不建议）。

**问：别人能用我电脑上的 LawMind 服务吗？**  
不能。桌面服务只监听本机回环地址（相当于只接受这台电脑自己的请求），并且需要令牌；不要把它反向代理到局域网。

**问：我做了什么操作，事后能查吗？**  
能。交办、修改、签批、导出等关键动作都有审计记录，可按案件、按时间导出，供内部留痕或合规检查。

**问：文书每段话的来源能查吗？**  
能。系统会为每段文字记录来源链：材料来源、AI 建议、律师修改/接受、自检修订与导出；在改稿页点「来源」按钮即可查看，导出时也可选择附为 Word 批注。

**问：审计日志是什么？**  
审计日志是 LawMind 对关键操作的完整留痕，包括谁、何时、做了什么、用了哪些来源与模型。它一旦写入就无法在软件内被事后修改；若有人手动改动磁盘文件，完整性校验会留下痕迹。你可以在「设置 → 系统体检」或案件详情里按时间导出，随时自查或交给合规检查。

**问：审计链如何防止篡改？**  
LawMind 在写入审计日志时，会同步计算一条只能单向追加的「链式指纹」：每一条记录都包含上一条的指纹，并再用本机独立保存的密钥做一次签名。这带来两层保护：

1. **同目录外锚**：系统会把链尾的最新指纹再追加到一份独立的外锚文件。如果只删改某一天的日志，外锚文件里的指纹就对不上，体检会报「截断」或「篡改」。
2. **外部锚**：你可以把工作区外的路径（如 U 盘、iCloud/OneDrive 本地同步目录）或一个 HTTPS 只写 URL 设为外部锚。系统每次写入审计后，会把带签名的最新摘要同步过去。即使攻击者同时改动了工作区里的日志和外锚，保存在外部位置的摘要仍然保留原始指纹，事后可用「验证审计链」按钮比对，发现不一致。

要启用，请前往「设置 → 工作区 → 审计外部锚」填写外部路径或 URL；保存后重启本地服务即可生效。验证按钮也在同一位置，点击后会比对当前链与外部锚，给出「通过 / 截断 / 篡改 / 签名无效」的结论。

**问：本地优先具体怎么体现？**  
你的案件材料、草稿、记忆、审计文件都存放在你自己电脑的本地工作区里，而不是 LawMind 的云端。模型 API 钥匙和连接配置由你自己持有，LawMind 只在你填写的配置里调用你指定的模型服务。备份时，把工作区目录复制到安全位置即可，密钥和临时运行数据默认不会混在备份里。

**问：出口代理和命令网关对我意味着什么？**  
LawMind 不会私自访问互联网或运行你电脑上的程序。它只在「工作区策略」里你明确写明的网络地址或命令范围内访问外部；没有写明的一律默认拒绝。换句话说，哪些网站能查、哪些外部工具能用，由你或你事务所的配置决定，系统不会自行越界。

**问：系统说「核对通过」，是不是法律上就没问题了？**  
不是。机械核对只是查定金上限、时效这类硬性数字与格式，**通过 ≠ 法律正确**。法律判断永远是你的；外发前请通篇审核。

**问：怎么备份？**  
备份你电脑上的 LawMind 工作区目录即可（升级前建议先备份）。具体位置在「设置 → 系统体检」里能看到。

## 七、案件卡片上的数字是什么意思？

在案件概览和 LawmindDesk 仪表盘里，你会看到几个**可解释的真实指标**，它们全部来自系统实际记录，不是 AI 估算的「安全分」：

- **已核对 X%**：机械核对规则已触发的比例。分母是系统已知的机械规则库（如定金上限、争议解决条款、条款编号连续性等）。数值越高，说明已跑过的核对越多；但通过≠法律正确，仍需你通篇审核。
- **N 项待拍板**：当前需要你签批或批准的稿件/动作数量。点进去即可处理。
- **N 项逾期**：案件里已过 deadline 且仍开放的待办事项（如出庭日、提交期限）。会标黄提醒，不标红制造恐慌。
- **最近活动**：该案最后一次发生交办、改稿、签批或交付的时间。
- **阶段标签（交办/改稿/签批/交付）**：系统按当前案件状态自动推导：有待签批→签批；有待改稿→改稿；有可交付成果→交付；其余→交办。

这些指标只回答「现在案件忙到什么程度、哪些事在等你」，不替代你的法律判断。

## 八、遇到问题

- **设置 → 系统体检**：一键自检（模型钥匙、工作区、各项服务是否正常），并给出修复建议。
- 结果不满意：在对话里直接纠正，或在改稿面改；系统会把你的纠正作为偏好候选，经你确认后记住。
