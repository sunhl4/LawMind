## 1. 为何 V2 仍不够

V2「Decision Inbox」只是把工程师监控台换成了律师收件箱，**壳还在**：

- 左案件轨 + 中列表 + 右详情 → 仍是桌面三栏心智
- 分段胶囊仍像「多视图产品」
- 律师进场仍要先选行，再找按钮

律师真实场景更接近：**桌上摊着一份待签文件**，签完下一份自动递上——不是打开项目管理软件。

## 3. 颠覆方案：Decision Ceremony（签批仪式）

### 3.1 一句话

> **打开「在办」= 进入今日签批仪式。**  
> 屏幕上只有「这一件」；队列默认隐身；动作后自动递上下一件。  
> 新任务永远回对话；助手后台进度只是细条，不是主舞台。

### 3.2 信息架构（不是三栏 App）

```
「在办」入口
├─ 有待拍板 → Ceremony Mode（全屏仪式，默认）
│   ├─ 当前决策卡 / 文书预览（主舞台）
│   ├─ 底部动作条：主 CTA + 退回 + 稍后
│   └─ 队列 = 角标「还剩 N」或 `L` 拉出胶片条（Filmstrip），默认收起
├─ 待拍板清零 → Clear Desk（今日已清）
│   └─ 一句状态 +「回对话下达」+ 可选「助手还在办的 N 件」
└─ 助手办理中 → Pulse（顶部 1 行，可展开为轻列表，永不与仪式抢等权）
```

不再有一级：「进行中 / 交出去的 / 按流程」。

### 3.3 布局（全屏仪式，非 Master–Detail）

```
┌─ 极简顶栏（~40px）────────────────────────────────────────────┐
│ LawMind · 今日拍板     股权转让纠纷 · 第 1/3     [队列 ▾] [对话] │
├─ Pulse（可选 1 行）──────────────────────────────────────────┤
│ 助手还在办 5 件 · 点此稍后看                                    │
├─ CEREMONY STAGE（~75% 视口）─────────────────────────────────┤
│                                                              │
│     ┌────────────────────────────────────────────────┐       │
│     │  文书预览 / 决策摘要（纸面隐喻，居中大卡）        │       │
│     │  标题 · 一句话为什么需要你 · 关键风险点           │       │
│     │  ── 依据与引用（折叠 paper trail）──             │       │
│     └────────────────────────────────────────────────┘       │
│                                                              │
├─ ACTION DOCK（固定底栏）─────────────────────────────────────┤
│  [ 进入文书台签批 ]          [ 退回补充 ]    [ 稍后 · H ]     │
└──────────────────────────────────────────────────────────────┘

按 L / 点「队列」→ 底部或右侧滑出 FILMSTRIP（缩略卡，非等宽列表栏）
动作完成 → 舞台内容替换为下一件（Superhuman 流），不退回列表首页
```

### 3.4 交互原则

1. **默认看不到完整队列**——只见「第 1/3」与角标。
2. **一屏一个主 CTA**（签批 / 批准 / 去对话补充，随类型变）。
3. **乐观前进**：稍后 / 签批后立刻下一件；`Z` 撤销。
4. **键盘**：`Enter` 主动作 · `H` 稍后 · `R` 退回 · `L` 队列 · `C` 对话。
5. **技术轨迹永不默认展开**；需要时在 paper trail 里。

### 3.5 文案（律师向）

| 旧                                   | 新                             |
| ------------------------------------ | ------------------------------ |
| 在办 / Agent 舰队                    | 今日拍板                       |
| 进行中 · Job · 轨迹                  | （删除一级）/ 办理过程（折叠） |
| 打开对话 + 进入文书台 + 取消（等权） | 一个主按钮 + 两个次要          |
| 工作流 / 队列 / 同步                 | 助手还在办（Pulse）            |

## 4. 与现状 / V2 对照

|        | 现状              | V2 Inbox           | **V3 Ceremony**          |
| ------ | ----------------- | ------------------ | ------------------------ |
| 结构   | 三 Tab + 等宽双栏 | 分段 + Index/Focus | **无列表默认；全屏仪式** |
| 主视线 | 卡片墙            | 右侧详情           | **文书/决策纸面**        |
| 队列   | 永远可见          | 永远可见           | **Filmstrip，按需**      |
| 完成后 | 停在详情          | 停在详情           | **自动下一件**           |
| 案件轨 | 常驻侧栏          | 常驻侧栏           | **顶栏一枚芯片即可**     |

## 5. 实现边界（确认后再写代码）

**做**：Ceremony 默认路由；Action Dock；Filmstrip；Clear Desk；Pulse；文案与键盘。  
**不做（本波）**：重做全局壳、砍对话页、把「按流程」做成画布。  
**映射**：`awaiting_*` → Ceremony 队列；running → Pulse；delegated → Pulse 子组或清零后次级。
