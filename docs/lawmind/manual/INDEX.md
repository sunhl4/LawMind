# 总索引

这本手册有 71 章 + 5 附录。这个文件是**反查入口**：你手上有一个问题、一个路径、一条命令、一个词，想知道看哪一章。

如果你还没有明确的检索目标，先看 [`README.md`](./README.md) 的「按角色选阅读路径」。

**怎么用**：下面五张表分别按「问题 / 模块路径 / 命令 / 术语 / 坑」组织。查表时用编辑器的搜索（`⌘F`）会比逐行读快。

## 七、怎么维护这份索引

- **新增一章**：在「二、按模块路径查」表里加一行（路径 → 章号），如果这一章解决了某类新问题，也在「一、按问题查」加上。
- **改了某章的章号或标题**：搜这份文件里那个章号，一起改。因为清单是手写的，**没有脚本会替你检查它是否过期**。
- **正文与索引冲突时以正文为准**——索引只是入口，不是事实来源。

维护正文本身的口径见 [`README.md`](./README.md) 的「写作约定」。
