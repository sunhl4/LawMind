# 第 26 章 交办话术与提示模板

这一章是实用向的：**同样的活，怎么说效果更好。**

说清要什么，把文件拖进来。照交给同事的方式说。分办在第 4 章。

## 26.1 三条基本原则

### 原则一：说清「要什么」，不用说「怎么干」

好：「审一下这份合同的违约责任，风险点标出来，能改的直接改。」

不好：「先读合同，然后找违约责任那一条，然后比对民法典关于违约金的规定，然后……」

原因：先读哪段、查哪条、用哪个工具，由系统安排。**你给的是目标，不是步骤。**

### 原则二：材料比话重要

同一句话，附了合同和不附合同，结果完全不同。合同、诉状、函件、发票、传票，把原件拖进来。

所以**能拖就拖，别用文字描述材料**。

### 原则三：不可逆的边界要写出来

外发、改原稿、覆盖原文，写进交办。

写了「不要改原稿」或「别发邮件」，这轮就不会把改稿或发出去当成必须完成的事（第 4 章）。

范围、风格、先不下结论，知道就补一句。不必每轮再附一份禁止清单。

## 26.2 合同类话术

| 你想干什么     | 这么说                                                         | 为什么这么有效                   |
| -------------- | -------------------------------------------------------------- | -------------------------------- |
| 审合同         | 「审一下这份合同的违约责任/付款条件/解除条款」                 | 点出要审的条款，并附上合同       |
| 审一批合同     | 「把这几份合同的付款条件和责任上限整理成一张表，每条要有出处」 | 要一张表，并且每条能指回出处     |
| 从零起草       | 「起草一份采购合同的框架，我方是买方」                         | 说清文书类型和我方立场           |
| 改一份合同     | 「改一下这份合同，把付款期限从 30 天改成 45 天，出修订稿」     | 说清改哪一句、改成什么、要修订稿 |
| 只要意见不改稿 | 「只出审查意见，不要改原稿」                                   | 写明不要改原稿，这轮就只出意见   |
| 统一称谓       | 「这几份文书里的『甲方』都改成『买方』，当事人名字也统一」     | 说清新旧称谓，以及要一起改的文书 |

**注意最后一条**：同一句在正文里出现多处时，说清是全部替换，还是只改某一处。没说清的那一条会跳过，不落笔。

## 26.3 诉讼类话术

| 你想干什么 | 这么说                                               |
| ---------- | ---------------------------------------------------- |
| 写起诉状   | 「按这份材料写一份起诉状，我方是原告」               |
| 上诉       | 「写一份上诉状，针对一审判决的第三项」               |
| 刑事       | 「这个案子在审查起诉阶段，写一份辩护意见」           |
| 家事       | 「离婚案，写一份起诉状，有两个孩子的抚养问题」       |
| 知产       | 「专利侵权，整理一下权利基础和诉讼路径」             |
| 证据整理   | 「把这些材料整理成证据目录，每条写清证明目的」       |
| 时间轴     | 「从这些材料里做一个时间轴」                         |
| 答辩       | 「对方起诉了，写一份答辩状，重点反驳第三项诉讼请求」 |

**知道阶段就写出来**（一审 / 二审 / 审查起诉 / 执行），文书格式更稳。没写也会出稿，缺的标【待定】。

想先看一版时间轴，就加一句「先出一版我看」。

## 26.4 检索与研究类话术

| 你想干什么 | 这么说                                       |
| ---------- | -------------------------------------------- |
| 查法条     | 「查一下民法典关于违约金过高的规定」         |
| 查类案     | 「找一下类似的买卖合同违约判例」             |
| 出备忘     | 「研究一下数据出境的合规要求，写个备忘」     |
| 要一句短答 | 「公司能不能单方面调岗？简短回答」           |
| 读网页     | 「看看这个链接里说什么：（贴 URL）」         |
| 深度研究   | 「把相关规定和正反依据都查清，写成一份备忘」 |

**几个要点**：

- 要备忘就说「写个备忘」。要一句短答就说「简短回答」。
- 贴了链接，就说要看这个链接里的内容。回复里的公网地址、工作区文件和画布也可以直接点开（第 3.2 节）。
- 要正反两面时，说「支持的和反对的观点都要」。

## 26.5 材料与档案类话术

| 你想干什么   | 这么说                                                         |
| ------------ | -------------------------------------------------------------- |
| 整理案卷     | 「把这份文件夹里的材料归位，抽出当事人和案由」                 |
| 谈话入档     | 「这是昨天和客户的谈话记录，整理一下，把当事人和案由记进案子」 |
| 收材料进案   | 「把这些文件收进本案」                                         |
| 材料整理     | 「本案材料有点乱，先给一个整理方案」                           |
| 修材料放错案 | 「这几份材料放到错案子里了，挪到 XX 案」                       |
| 记期限       | 「记一下：下个月 15 号之前提交证据」                           |
| 传票         | （拖着传票照片）「记一下」                                     |
| 建案件       | 「新建一个案子，叫 XX 公司买卖合同纠纷」                       |

想先看方案，直接说「先给方案」。

## 26.6 计算类话术

| 你想干什么 | 这么说                                                          |
| ---------- | --------------------------------------------------------------- |
| 劳动补偿   | 「他工作了 3 年 7 个月，月薪 1 万，被违法解除，算一下能拿多少」 |
| 加班费     | 「算一下这两年的加班费，平时加班 120 小时，周末加班 60 小时」   |
| 期限       | 「一审判决 3 月 10 日送达，上诉期什么时候届满」                 |
| 诉讼费     | 「标的额 200 万，一审受理费多少」                               |
| 表格核算   | 「把这份 Excel 里的金额汇总一下，出个对照表」                   |

**关键**：把**要素给全**（工作年限、月薪、解除性质、日期）。缺了要素系统会标缺口，不会瞎算——这是设计（第 21 章那两条「不得口算」的验收标准）。

## 26.7 交付与导出类话术

| 你想干什么 | 这么说                                    |
| ---------- | ----------------------------------------- |
| 出 Word    | 「出一份 Word」                           |
| 出修订稿   | 「出一个带修订痕迹的 Word，放我桌面」     |
| 出 PPT     | 「做成培训课件，12 页左右」               |
| 写文件     | 「把这份意见书写成一个 md 文件放工作区」  |
| 导出表格   | 「导出成 xlsx」                           |
| 指定位置   | 「放到下载文件夹」/「放到这个案件目录里」 |

**「放我桌面 / 下载 / 文稿」**这三个是白名单位置（第 8 章）。指名之后系统会写到你点名的位置。

## 26.8 自动化类话术

| 你想干什么       | 这么说                               |
| ---------------- | ------------------------------------ |
| 从一件活变自动化 | 「以后每周一都这样来一次」           |
| 建自动化         | 「每周五下午给我一份本案进展小结」   |
| 邮件处理         | 「每天早上把需要我回的邮件整理出来」 |
| 续展监控         | 「提前 30 天提醒我这些合同的续展」   |

**注意**：说一句就能建起自动办件。模板会写好四句可改的确认（第 17 章）。把「办完是什么样」或「哪些事必须先问我」清空之后，不能创建。

## 26.9 协作类话术

| 你想干什么       | 这么说                                   |
| ---------------- | ---------------------------------------- |
| 派活             | 「让合同助手先审一遍，把结论给我。」     |
| 找特定岗位       | 「找一个做合规的助手看一下这段」         |
| 问同事（同步等） | 「问问研究助手法条里怎么规定，等它回复」 |
| 请人审           | 「让另一位助手审一下这份稿的准确性」     |
| 开个会           | 「开个会讨论一下这个案子的和解方案」     |

**关键**：被派的助手看不到你的对话，所以**任务要说全**（要什么、不要什么、有什么材料）。

## 26.10 记忆与口径类话术

| 你想干什么 | 这么说                                    |
| ---------- | ----------------------------------------- |
| 记偏好     | 「以后所有合同的违约金都按不超过 30% 写」 |
| 记口径     | 「我们所在管辖条款上一律写单一机构」      |
| 撤销写入   | 「撤销刚才那次写入」                      |
| 查记忆     | 「你都记住了我哪些偏好？」                |

**注意**：说「记住」不会直接写。它会变成一条**待确认建议**，你在记忆库确认才落盘（第 6 章）。

## 26.11 逆向：哪些话会把事情带偏

| 不好说法                   | 问题                         | 改说                             |
| -------------------------- | ---------------------------- | -------------------------------- |
| 「帮我处理一下这个」       | 没有产出，也没有材料         | 说清要产出什么，并把文件拖进来   |
| 「随便写一份」             | 看不出要意见书、备忘还是函件 | 说清类型（意见书 / 备忘 / 函件） |
| 「按我说的步骤来」         | 把模型和工具的安排收死       | 只说目标                         |
| 「这个不用检索，你直接说」 | 备忘仍会交，缺口标【待核实】 | 让它检索；没命中就标【待核实】   |
| 「尽快」                   | 没有时间信息                 | 给具体时间约束                   |

备忘没命中检索，已写的部分照样交，缺口标【待核实】。合规报告、学习材料和培训课件不一样：没有可用主张，或只命中演示语料时，这轮停住，不用演示数据把正文扩写完。

附上合同之后说「看看这份合同」，仍然按合同审查来办。要改稿时，直接说改哪一处、要修订稿。

## 26.12 什么时候把边界写出来

外发、改原稿、覆盖原文，用自然语言写进交办：

| 边界       | 怎么说                         |
| ---------- | ------------------------------ |
| 不改原稿   | 「不要改原稿」「只出意见书」   |
| 不发邮件   | 「先不要发，给我看」           |
| 不覆盖原文 | 「在副本上改，不要覆盖原文件」 |

范围、立场、先整理后下结论，知道就补一句，例如「只看违约责任那一章」「我方是买方」「先整理材料」。这些是目标，不必写成每轮必填的禁止清单。

## 26.13 一个完整的好交办长什么样

```text
审一下这份采购合同的违约责任和解除条款。我方是买方。
风险点要标出条款位置，能给改法就给改法。
只出审查意见，先不要改原稿。
```

这四句分别说了要审什么、我方立场、风险标在哪条以及能改的写法、先不要改原稿。比写一大段「请仔细阅读……并注意……」有用。

## 26.14 已知坑（本章相关）

- **说清要什么，把文件拖进来。** 照交给同事的方式说。
- **材料常常比话更重要。** 附了诉状和附了合同，办出来的东西不同。附上合同后说「看看」，仍然按合同审查来办。要修订稿就另外说。
- **外发、改原稿、覆盖原文要写出来。** 范围和写法交给模型。
- **说「记住」不等于会记住。** 要走确认。
- **立场和计算要素给全。** 缺金额、年限、日期会标缺口，不会口算。阶段知道就写；没写也会出稿，缺的标【待定】。
- **同一句出现多处，说清改全部还是改一处。** 没说清就跳过该条，不落笔。
- **别描述步骤。** 判断空间留给模型。
