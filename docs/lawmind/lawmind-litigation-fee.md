# 诉讼费估算（litigation fee）

> 模块：`src/lawmind/litigation/litigation-fee.ts` · 金额解析 `claim-amount.ts`
> 版本：`LITIGATION_FEE_VERSION = 1` · 出处：`诉讼费用交纳办法（国务院令第481号）` · 施行日：`2007-04-01`

## 为什么单独成模块

`SECURITY.md` 的硬约束：**错误的法定参数比没有规则更糟**。费率表逐档带 `source` + `effectiveFrom`，
改动必须留痕；幅度类收费不代选具体值。

## 已实现

| 项目           | 条文               | 口径                                                                                                                                                                                               |
| -------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 财产案件受理费 | 第十三条（一）     | 分段累计，10 档：≤1 万 50 元；1 万–10 万 2.5%；10 万–20 万 2%；20 万–50 万 1.5%；50 万–100 万 1%；100 万–200 万 0.9%；200 万–500 万 0.8%；500 万–1000 万 0.7%；1000 万–2000 万 0.6%；>2000 万 0.5% |
| 保全申请费     | 第十四条（二）     | ≤1000 元 30 元；1000–10 万 1%；>10 万 0.5%；**上限 5000 元**                                                                                                                                       |
| 执行申请费     | 第十四条（一）2    | ≤1 万 50 元；1 万–50 万 1.5%；50 万–500 万 1%；500 万–1000 万 0.5%；>1000 万 0.1%                                                                                                                  |
| 支付令         | 第十四条（三）     | 比照财产案件受理费 **1/3**                                                                                                                                                                         |

## 幅度类：返回区间，不猜数

离婚 50–300 元、人格权 100–500 元、其他非财产 50–100 元、管辖权异议 50–100 元、
知产无争议金额 500–1000 元 —— 第十三条明确「省级人民政府可以在幅度内制定具体交纳标准」，
因此引擎返回 `{ kind: "range", minYuan, maxYuan, note }`，由使用者按受诉法院所在地标准取值。

离婚的财产分割（>20 万部分 0.5%）、人格权的赔偿额（5 万–10 万 1%、>10 万 0.5%）
是**超出部分加收**，已实现，且加在区间两端。

## 数值校验

测试用官方「简易公式」（标的 × 费率 + 常数）交叉验证每一档：

| 档            | 简易公式           | 交叉验证 |
| ------------- | ------------------ | -------- |
| 1 万–10 万    | 标的 × 2.5% − 200  | ✅       |
| 10 万–20 万   | 标的 × 2% + 300    | ✅       |
| 20 万–50 万   | 标的 × 1.5% + 1300 | ✅       |
| 100 万–200 万 | 标的 × 0.9% + 4800 | ✅       |
| 200 万–500 万 | 标的 × 0.8% + 6800 | ✅       |

## 使用位置

- **agent 工具**：`calculate` 的 `op: litigation_fee`（`caseKind` + `amountYuan` 或 `amountText`，
  可同时传 `preservedAmountYuan` / `executionAmountYuan` / `simplified` / `mediationOrWithdrawal`）。
- **工作台**：`案件信息` → 「受理费」，按卷宗标的金额即时估算，并显示减半对照。
  视图口径见 `apps/lawmind-desktop/src/renderer/matter/litigation-fee-view.ts`（纯函数 + 单测）。

## 金额解析（`claim-amount.ts`）

支持 `32100`、`32,100.50`、`32,100 元`、`3.21万元`、`人民币 32100 元`、`叁万贰仟壹佰元`、`三万二千一百元`。
**歧义时必须失败**：出现多个不同金额（如「本金 32100 元，另案 50000 元」）返回 `ok: false` 与候选项，
界面显示原因，不按错的金额算出错的受理费。裸数字（案号年份）不算金额。

## 改费率时的规矩

1. 改 `src/lawmind/litigation/litigation-fee.ts` 的费率表；
2. `LITIGATION_FEE_VERSION` +1，`effectiveFrom` / `source` 同步（新办法或修正案）；
3. 更新测试里的交叉验证值；
4. **参数与措辞待执业法律顾问复核**（与 `src/lawmind/lint/statute-params.ts` 同一惯例）。

## 边界

- 只做确定性算术，不做法律判断（如是否属财产案件、是否适用简易程序由律师定）。
- 不处理缓交/减交/免交（司法救助，第五条等）。
- 不处理上诉案件按上诉请求数额计费、反诉减半等程序性情形，需要时按同一费率表另算。
- 最终数额以法院核定为准。
