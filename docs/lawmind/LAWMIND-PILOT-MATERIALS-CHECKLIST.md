# LawMind 需要你提供的材料清单

> **用途**：这是一份**待办清单**，不是要求一次交齐的东西。每条都写明「精确要什么 / 为什么需要 /
> 拿到后解锁什么 / 谁来做」。**拿不到某一份，只会让对应那一栏空着，不影响其他。**
> 生成于 2026-09-22，与 [LAWMIND-PILOT-MEASUREMENT-PROTOCOL.md](./LAWMIND-PILOT-MEASUREMENT-PROTOCOL.md)（预注册）
> 配套使用：那份定「怎么算」，这份定「算什么需要什么材料」。

## D. 不需要的（免得多花钱 / 多担风险）

- **任何 API key / 密钥** —— 除 A3 的 pkulaw 外，一个都不要（模型 key、邮箱密钥、许可激活码都不给）。
- **当事人真实姓名、未脱敏案卷、客户名单**。
- **云端账号** —— 本产品不出站，给了也没用。
- **证书私钥的明文副本** —— A1 只需装进钥匙串，或给 `CSC_LINK` 指向的 `.p12` + 密码即可。

## F. 材料到手后我的动作（固定，且已预注册）

1. 出**周表**：一次通过率 / 机械核对逃逸率 / 改稿幅度中位（含样本量与门槛判定）。
2. 给**一句话结论**：在变好 / 在变差 / 分不清 / 证据不足。
3. 按 [预注册协议](./LAWMIND-PILOT-MEASUREMENT-PROTOCOL.md) §6 的对应动作执行 ——
   **不修改口径去迁就结果**。

复算命令（可自查）：

```bash
pnpm lawmind:north-star-trend -- --workspace <试点工作区> [--window 90] [--json]
```

> 退出码恒 0 ——「样本不足」是**结论**，不是错误。
