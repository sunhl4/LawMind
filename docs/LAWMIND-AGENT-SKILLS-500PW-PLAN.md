## 1. 编制假设

### 1.1 参考班组（默认）

| 角色            | 代号 | 稳态投入 | 职责                                       |
| --------------- | ---- | -------- | ------------------------------------------ |
| 引擎 / 后端     | EN   | 1.5 FTE  | `src/lawmind`、桌面 server、API、Job、gate |
| 桌面 UI         | UI   | 1.5 FTE  | renderer、e2e、信息架构                    |
| 设计 / 产品     | DX   | 0.5 FTE  | 线框、交互、文案、验收标准                 |
| 质量 / 测试     | QA   | 1.0 FTE  | 单测策略、e2e、黄金集、回归                |
| 内容 / 法务流程 | CT   | 0.5 FTE  | 中国包剧本、必核清单文案、许可证           |

**参考班组合计 ≈ 5 FTE → 500 人周 ≈ 100 个日历周（约 23 个月，含节假日缓冲需另加）。**

### 1.2 班组换算

| 班组规模      | 日历周 ≈ | 约月数           |
| ------------- | -------- | ---------------- |
| 5 FTE（默认） | 100 周   | ~23 月           |
| 8 FTE         | 63 周    | ~14.5 月         |
| 10 FTE        | 50 周    | ~11.5 月         |
| 2 FTE         | 250 周   | 不建议按本表硬扛 |

换算：`日历周 ≈ ceil(500 / FTE数)`；并行时优先加 UI+EN，CT 在 S5 可临时升到 1.5。

### 1.3 人周会计规则

- 1 人周 = 一名全职约 4.5–5 个有效工作日（含会、CR）。
- 表中「本周投入」按角色拆分，周合计目标 **5.0±0.5**。
- **缓冲**已编入各 Wave 末「硬化周」，不再另加隐形 20%。
- 超支时：**先砍 Firm 密度与精美 PDF，不砍 Solo 主路径验收**（见硬规则）。

### 1.4 Solo-first 硬规则（沿用）

1. Solo 默认清爽；Firm 密度可折叠。
2. 一人跑通：分诊 → 专案组 → 必核 → 导出。
3. Solo 默认串行 Fleet；「更快模式」可选。
4. `preferClassicChatHome` 逃生舱。
5. 第三方 skill **只借鉴思想**，自研文案进发行包。
