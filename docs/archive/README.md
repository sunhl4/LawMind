# LawMind 文档归档区（只读封存）

本目录收录 **历史文档**，于 2026-09-03「文档体系减法」中自 `docs/` 根移入封存。

## 口径

- **只读封存**：归档文档是历史快照，记录当时的方案、评审与口径；**不再更新、不做回改**。
- **口径以现行文档为准**：归档文档之间、归档与现行文档之间存在表述冲突时（如 Solo 门禁口径、架构分层、e2e 计数），一律以 `docs/` 现行文档与仓库根 `GOALS.md` / `SECURITY.md` 为准。
- **链接说明**：归档文档内部的交叉链接保持封存时原样；指向现行文档的相对链接可能已失效，请按文件名在 `docs/` 根目录查找现行版本。
- **检索提示**：工程检索（含 agent 检索）命中本目录时，应注意其为历史口径；现行入口见 `docs/LAWMIND-REPO-LAYOUT.md` 顶部「现行文档清单」。

## 为什么归档

评审（2026-09）发现 75+ 篇 append-only 文档越过人类可读阈值并出现自相矛盾。收敛方案：现行文档收敛至少量权威篇目，其余移入本区封存，保留历史可追溯性（不删除）。

## 查阅方式

- 按文件名直接查阅；文档站同步发布于 `/archive/` 路径下。
- 各篇的历史定位与落地状态，可结合 `CHANGELOG.md`（仓库根）与 `GOALS.md` 第十四期索引回溯。
