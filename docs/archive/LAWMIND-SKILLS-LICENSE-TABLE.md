## 收录检查清单（PR）

1. 标明来源 URL / commit 与 SPDX（或「未声明」）。
2. 若非 MIT/Apache/BSD，默认 **拒绝 vendoring**。
3. 允许写入仓库的仅限：自研 `workspace/lawmind/skills`、本表致谢、测试夹具（脱敏）。
4. 变更本表需在 PR 描述写明「许可证影响：无 / 新增行」。
