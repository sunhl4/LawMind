## 0. 我们做什么

LawMind 是律师的交件系统：律师说需求、给出材料，系统交回一份可以直接用的稿。

它不是法律版的 Codex，也不是法律版的 Cursor，也不是把 Harvey / Legora 的按钮搬到本机。编码 agent 的循环形态可以参考；它们的交互（计划模式、自配 Skill、插件市场、工程师看着 diff 开车）不进入律师主路径。

前瞻来自另一件事：主流 agent 框架在长任务上反复撞同一类墙。下一轮不靠把这些框架再对齐一寸来过墙，而靠一组新的执行原语。用的是量子信息在对角态上仍然成立的状态语法——混合态、乘积融合、非破坏检查、部分迹、延迟投影、可逆直到测量——全部落在普通计算机上。量子计算机与量子线路模拟器不进入交件回合；何种离线实验才允许做，见 §9.5。

## 0.1 为什么必须越过大模型和现有 agent 理论

顶流 agent 已经把「模型加工具循环」做到能用。再往上走，瓶颈不在循环外壳，在大模型本身、以及这套外壳和模型共用的假设。提示词、投票、辩论、更长上下文、更强的默认模型，都还留在这些假设里面。

大模型带进每一次交件的缺陷：

1. **自回归锁死。** 下一个词取决于已经写下的前缀。前缀错了，后面只能圆，回不到另一个内部一致的世界。这是模型结构，不是提示词能拆开的。
2. **局部流畅冒充全局成立。** 训练目标是局部似然。读起来像律师，和当事人、金额、定义、引用同时成立，不是同一个目标。
3. **不确定被写成确信。** 一次采样是一条轨迹，看起来像纯态。证据弱的命题没有「振幅近零就不得写成事实」的位置。
4. **上下文被当成真相。** 压缩、噪声一冲，约束就没了。加大窗口只是把退相干推迟，真相仍放在会被冲掉的介质里。
5. **生成不可逆。** 错句写进稿，撤不干净，只能再生成一遍。思考中途的外发是同一种不可逆。
6. **自己的话喂回自己。** 不确定的中间叙述再进上下文，幻觉被当成新证据。观测扰动了被观测的系统。

现有 agent 理论默认：**模型持有状态，引擎负责调用**。模型再强，上面六条还在。下一层是把状态从模型里拿出来。拿不出来的部分，允许重构运行时，而不是在现有循环上再贴一层对齐补丁。

每个后续原语都要能指明它压住上面哪一条。指不明的改动，不算本合同里的创新。

## 1. 已定产品合同（开发时不得重开）

律师侧只保留两件事：开口交办；对真授权拍板（外发、以及律师点名要改的原稿范围）。计划、拆任务、选能力、检索、改稿、自检，全部在引擎里做完。律师看到的是可用的稿。

| 不做                         | 原因                                                               |
| ---------------------------- | ------------------------------------------------------------------ |
| 律师可见的 Plan Mode         | 计划是模型的草稿纸。律师要的是终稿，不是等律师签批的步骤表。       |
| 律师自配 Skill / MCP / Agent | 铁律 4 由我们消化；铁律 1 要求开箱。能力进内置包，按任务自动套上。 |
| 中途追问「要不要继续」       | 任务北极星：中间步骤不打断。缺事实写进稿里【待核实】，回合完成。   |
| 会议室、多助手互辩           | 2024–2025 的证据：辩论增益多来自集成，不来自互喷；又贵。           |
| 把可审计当成质量             | 记录过程不等于稿能用。质量看交件本身。                             |

内部仍可以有计划（`update_plan`、子工任务书）和 Skill 正文。它们不成为律师必须进入的模式，也不成为设置项。

「直接可用」的定义：能改、能算、能检索、能成套交件。缺事实时，稿里写清缺口如何影响结论，而不是停下来采访。

「满足日常需要」的定义：检索、尽调、合同、诉讼、交易、合规、材料、计算、办公交付，开箱就能出可用稿。新场景的做法是我们每期把外部能力验证后收进默认包。设置项应随模型变强而变少。

可以留在设置里、且不挡住这一次交办的：模型钥匙，以及极少数真授权（跨案检索、外发账号）。没有钥匙时诚实说连不上模型。推断出的立场和文书类型写进稿，让下一次更好，不挡住这一次。

## 3. 主流框架已经撞上的墙

这些墙是 Codex、Cursor、Claude Code、OpenHands、Harvey 文档 agent、以及 2024–2025 论文里的同一类失败。再抄一层循环，过不去。

1. **收敛得太早。** ReAct 每选一次工具就塌缩一次，轨迹早早锁死在单一读法上；Plan Mode 让人在执行前再塌缩一次。两条路都毁掉还没提交的其他做法。律师主路径要的是相反的事：内部可以分叉，对外只有一次测量——交件。
2. **长任务退相干。** 压缩、摘要、工具噪声会把早期约束冲掉。Codex 自己承认工具输出和推理会被结构性丢掉。法律里这叫红线在第几十轮静默失效。
3. **并行写同一份稿会互相覆盖。** Harvey 的解法是每支一份文档分支再合并。多数开源 agent 没有这层，只有「把摘要塞回父对话」。
4. **投票不是干涉。** 多数票把互相矛盾的读法平均掉，矛盾被藏进平均值，而不是被标成待核实。两条互相矛盾的结论不该比谁更长；它们应相消，命题改成待核实。多智能体辩论把这个过程变成聊天，成本上去，稿的质量不上去。
5. **验收装在生成后面。** 先写一大段，再请另一个模型当法官。法官贵、飘、而且常把整篇打回。缺的是便宜、确定、每步都能测的不变量。
6. **子工克隆了不该克隆的上下文。** 把父提示词缩写后塞给子工，既漏掉纠缠在一起的定义，又带进无关案情。不可克隆：子工应只拿该任务的约化态。
7. **从空白高温生成。** 长文书自由生成，熵太高，后半段必漂。应从已验证的骨架连续变形，只在骨架的正交补里自由写。
8. **不可逆动作发生在思考中途。** 外发、删卷宗是测量，不是工具调用。测完就出不去了。

第 19 期和「交办即终稿」已经在墙上钉了几颗钉子（父会话 + sidecar、压缩后红线重注、空红线不得完成、外发进待发信、缺口进稿不停写）。下一轮把钉子收成一套结构，而不是再钉第 20 颗同类钉子。

## 4. 从量子计算借什么

不运行量子计算机，不在界面写「量子」，不把隐喻写进系统提示词。借的是物理里已经证明好用的结构：

| 量子概念      | 在交件系统里指什么                                                                 |
| ------------- | ---------------------------------------------------------------------------------- |
| 叠加          | 交件前，对同一命题保留若干内部一致的读法，不先选一个给律师看。                     |
| 干涉          | 并行结论在合并前按命题对齐：同向加强则入稿，反向相消则该命题待核实。               |
| 测量          | 律师看见的那一次塌缩就是可用的稿。调试通道可以看中间态，主路径不展示。             |
| 延迟测量      | 能在塌缩前算完的，都先算完。外发是最后才允许的不可逆测量。                         |
| 纠缠          | 定义项、称谓、金额、交叉引用绑在一起。改一处不更新纠缠支撑，状态不合法。           |
| 部分迹 / 约化 | 子工只携带与本任务对易的那一块状态，其余迹掉。                                     |
| 退相干        | 长任务里环境（工具噪声、压缩）把相位冲掉。要抑制的是冲掉不变量，不是把窗口再加大。 |
| 稳定子纠错    | 用一小套对易的不变量做综合征。综合征全绿就不重采样；翻转了只修纠缠到的那一块。     |
| 绝热演化      | 从低能、已验证的骨架缓慢变形到本案事实，避免高温自由生成。                         |
| 振幅放大      | 检索不是一次 top-k。每一轮按「是否加强稳定子」提高候选材料的权重。                 |

经典对应物已经存在：信念状态、不变量断言、可逆编辑、延迟提交、依赖图。量子语言的用处是让这些东西变成**同一套交件物理**，而不是七个互不相关的补丁。

### 4.1 重构命题：引擎持有态，模型只采样

若现有 `runTurn` 守不住这条命题，重构运行时。不把「法律版 Codex」的循环当成不可动的骨架。

- **态在引擎。** 命题、振幅（有没有独立证据）、纠缠（定义、称谓、金额、引用）、稳定子，都在引擎里。散文是测量读数，不是态本身。
- **模型是采样器。** 它只在引擎给出的约化态上提议下一步变形：怎么争、怎么写、先读哪份。它不保管红线，不裁判矛盾，不决定外发。模型变强，采样更好；态仍不搬回上下文。
- **两种测量分开。** 稳定子是非破坏测量：查不变量，不把起草轨迹塌成一条。交件是投影测量：这时才变成律师看见的稿。Plan Mode 是在不该投影的时候投影。
- **纠错要勤于积累。** 长任务稳，不是因为上下文够长，而是综合征抽得够勤，局部错误来不及积成整篇。高于这个频次阈值，再强的模型也会漂；低于它，有限的模型也能把长稿压住。
- **振幅门槛对幻觉。** 没有独立证据的命题振幅近零，不得写成事实句。这是结构限制，不是「请务必引用」的提示。
- **交件前可逆。** 错了做逆运算，只动纠缠到的那一块，不整篇重采样。外发才是不可逆测量。

| 原语               | 压住的缺陷                             |
| ------------------ | -------------------------------------- |
| 交件即测量         | 收敛得太早；中途观测把幻觉喂回去       |
| 稳定子综合征       | 局部流畅冒充全局成立；错误沿长任务积累 |
| 约化子工           | 上下文被当成真相；子工克隆不该克隆的态 |
| 干涉合并           | 不确定被写成确信；投票把矛盾平均掉     |
| 纠缠改稿           | 改一处、其余副本各自漂移               |
| 绝热起草           | 从空白生成，后半段离开骨架             |
| 可逆直到不可逆测量 | 生成不可逆；思考中途就把外发做掉       |

### 4.2 数学对象与工程计划

量子启发在这里是一条限制：只用**已选好指针基、退相位之后的对角态**。不存复数相位，不跑量子线路，不声称 Grover 加速。相位没有可校准的法律数据，存了就是自由参数。商业上可跑的是稀疏因子上的经典概率，外加量子信息里仍然成立、而且在对角态上可以精确写出的几条规则。

#### 态

一份交件的态是因子图，不是全文，也不是 \(2^n\) 维振幅。

每个因子 \(i\) 有稳定锚（条款、定义项、金额槽、期限槽、引用槽、当事人角色之一）和至多 4 个互斥读法。对角密度就是这些读法上的概率：

\[
\rho_i(o)\ge 0,\qquad \sum_o \rho_i(o)=1.
\]

纯度

\[
\gamma_i=\sum_o \rho_i(o)^2=\operatorname{Tr}(\rho_i^2)\in\Big[\frac{1}{|O_i|},1\Big].
\]

二元读法时 \(\gamma_i\ge 0.75\) 等价于主导读法质量至少约 \(0.85\)。交件（投影测量）只在此时写成确定句；否则写成混合态，也就是【待核实】，列出质量 \(\ge 0.25\) 的读法。禁止对混合态取 argmax。

\(n\le 500\) 个因子时，态的大小是 \(O(n)\)，不是指数。确定性更新目标在一次交办里低于 50ms。常数 \(\gamma^\star=0.75\)、\(\varepsilon=0.25\) 写在引擎里，不进律师设置；要改就改代码并补 cassette。

没有锚的自由文本不建因子，不参与下面的相消。它只能作为某锚的证据引用。

#### 干涉 = 独立证据的逐点乘积

两支条件独立的证据记为 \(\rho,\sigma\)。融合

\[
\rho'(o)\propto \rho(o)\,\sigma(o),
\]

再归一。同向的读法被乘积放大，只有一方支持的读法被压低。这就是对角态上的干涉：加强与相消都来自乘积，不来自手写相位。

支撑不相交（乘积恒为 0）时，结果没有定义，记 `conflict`，两侧依据都留下，渲染为【待核实】。不选边，也不发明第三种读法。

父模型只把 \(\rho'\) 的渲染结果写成句子。它不判断「是否矛盾」。

#### 约化 = 1-hop 边际

纠缠不存成联合振幅，而存成稀疏边。子工的约化态是：任务书点名的锚、这些锚的 \(\rho_i\)、以及图上距离 \(\le 1\) 的因子和边。其余因子视为已求迹，不写入子工提示。这是对真部分迹的稀疏近似，近似误差就是被丢掉的长程边；所以边必须少，而不是把父提示词截短来冒充约化。

#### 稳定子 = 非破坏测量

\(S_k\) 是只读纯函数，值域 \(\{+1,-1\}\)，不调用模型。综合征是这些值拼成的向量。因为只读，检查顺序不影响结果，这就是这里需要的「对易」。

\(S_k=-1\) 时，修复只作用在 \(S_k\) 触到的因子上，每个因子每回合至多 2 次。仍失败则该因子标 `uncorrectable`，强制 \(\gamma_i<\gamma^\star\)，交件写【待核实】，回合完成。不新增停顿。

第一闭集只收三条（第四条有条件），见 §8。定义项全图不在第一闭集里：那是纠缠边，不是第一批稳定子。

#### 绝热 = 有限步同伦，每步查能隙

不构造量子哈密顿量，也不做变分求解。骨架读法记为 \(s\)，本案要绑上的事实槽记为 \(f\)。步数 \(K\le 6\)，\(t_k=k/K\)。第 \(k\) 步只重写那些与「本步新绑上的事实」相邻的因子。接受条件是本步综合征仍全为 \(+1\)（能隙还在）。失败则把步长减半一次；再失败就把这些因子标混合并继续。不问律师，不整篇推倒。

#### 检索放大 = 乘性权重

候选池上限 200，轮数 \(R\le 3\)，步长 \(\eta=1\)：

\[
w_j\leftarrow w_j\exp(\eta\, a_j),\qquad a_j\in\{-1,0,+1\},
\]

\(a_j\) 是该材料与稳定子是否一致的确定性分数，然后保留权重最高的 20 条。这是对数域里的振幅放大，不是量子搜索，不承诺平方加速。

#### 可逆 = 历史胶带上的逆运算

交件前每笔写带逆运算。律师改一处时，撤销光锥（该锚 + 1-hop）里的写，只重采样这些因子，只复查它们的稳定子，至多 2 次。外发与删除案件丢弃可逆义务，是仅有的不可逆测量。

#### 计划

| 阶段 | 交付                                                    | 压住的缺陷                             | 验收                                                                        |
| ---- | ------------------------------------------------------- | -------------------------------------- | --------------------------------------------------------------------------- |

## 5. 七个原语

下一轮讨论从这里选先做哪一个，不要求一次做完。每个原语都有现有代码里的种子。能在现有循环里升成结构的，就升；守不住「引擎持有态」的，重构那一段运行时。不把对齐补丁当成创新。

### 5.1 交件即测量

律师主路径上，唯一的测量是可用交件。内部分叉保持未测量。

已有种子：交办即终稿（澄清硬闸退役；验收打满仍完成，缺口写进稿）；无任务回合不重跑流水线。

尚未成为结构的部分：中间计划、子工全文、工具轨迹默认不构成律师必须响应的状态。调试需要时走现有事件，不新开一种「请律师看计划」的模式。

### 5.2 稳定子综合征

每一轮工具边界测一小套**确定性**不变量，不先叫审稿模型：

- 引用标识必须落在本轮来源包内
- 金额、期限与规则引擎结果一致
- 当事人称谓在一份稿里只有一套
- 定义项的使用点都还指得到定义
- 修订轨不是整句删加整句增，且空修订不算完成
- 样本库命中不得写成权威源

综合征全绿：不重采样、不再请 Guardian 看同一份未变的稿（证据包哈希相同则跳过，这一点已有）。某一条翻转：只重做纠缠到该条的片段，不把整篇打回律师。重试必须有顶；打满仍按「交办即终稿」收口——`completed` + 缺口写【待核实】，不新增任何停顿点。

约束：稳定子必须是可机器判定的事实，不得变成「禁止某类措辞」的清单。否则违反铁律 5。

### 5.3 约化子工

父模型写任务书。子工系统状态是该任务的约化：目标、非目标、材料切片、与本任务纠缠的定义项、工作方式包。父会话的其余历史明确丢弃。

已有种子：`draft_worker` / `explore_folder` 不嵌套完整 `runTurn`；L2 按 role 装包；父会话只收摘要。

尚未成为结构的部分：约化是显式的迹运算（留下什么、丢掉什么写在契约里），不是摘要预算——现行的 3200 字摘要池只管「父会话收多长」，不管「子工带走什么」。续跑用 `resume_id` 回到同一约化，不新开一工克隆另一份父上下文。

### 5.4 干涉合并

同一轮多支子工返回后、下一次父模型采样前，引擎按命题做干涉，而不是把对照表交给父模型凭感觉宣布「没有冲突」：

- 结论相同且来源独立：加强，进入交件依据
- 同一命题结论相反：相消，该命题写成【待核实】，两侧依据都留在稿里
- 重复引用合并为一次

父模型只给存活下来的态写正文。它不再兼任冲突裁判。

两条前提，决定这条路是不是真的确定性：

1. **命题要有稳定锚。** 干涉按条款 ID、稳定子条目、抽取表的行这类可寻址锚对齐；自由文本结论不参与相消，只参与加强。没有锚就会退回「再请一个模型当裁判」，等于把问题下移一层。
2. **干涉不拦回合。** 相消只把命题写成【待核实】，回合照常完成。它是标注算子，不是新的硬门禁；否则违反铁律 5 和「交办即终稿」。

§8.1 已确认：共享锚由引擎按逐点乘积融合。支撑不相交写成【待核实】。父模型只写融合后的句子。

### 5.5 纠缠改稿

一次改稿是作用在依赖图上的运算：定义项、交叉引用、金额、当事人角色是纠缠算子。锚定过宽或纠缠支撑未一起更新，则整批零写入。

已有种子：`apply_surgical_edits` 跨文书先全批预检再落笔；最短改动；先例术语自适应。

尚未成为结构的部分：依赖图是交件的一等状态，不只是工具参数上的 `task_ids`。长文档按纠缠块分片，各支改副本，测量前确定性合并成一条修订轨。律师仍只看到一份红线稿。

### 5.6 绝热起草

大任务从已验证骨架出发（内置母版、本案上一份已通过机械综合征的交付、或法条结构），把本案事实连续绑上去。自由生成只允许发生在骨架覆盖不到的补空间。

这针对「长久任务质量漂」：漂通常来自后半段离开了前半段的骨架，不是来自窗口不够大。

已有种子：起诉状无母版时的栏目骨架、最短 span、模板化交付优先。

### 5.7 可逆直到不可逆测量

交件前的写入应当可回退；不可逆测量只有外发和删除案件。思考过程里不测量。今天 `revert_desk_write` 只覆盖部分写侧（整理、桌面写），覆盖缺口按本合同如实补齐，不宣称已可逆。

已有种子：外发写入待发信，回合不中断；`revert_desk_write`；`toolRequiresLawyerPause` 恒为假；iCloud 未落盘与伦理墙仍停，因为那是真阻塞，不是流程仪式。

## 8. 开发前要拍板的问题

下面五条已确认，并按 §4.2 的 A→E 落地。

### 8.1 干涉由引擎做，规则是乘积，不是词表

同意把矛盾裁判从父模型挪到引擎。规则只采用 §4.2 的逐点乘积：共享锚上独立证据相乘再归一；支撑不相交就记 `conflict` 并写成【待核实】，不选边。纯度 \(\gamma_i\ge 0.75\) 才写确定句。没有锚的自由文本不参与相消。父模型只写渲染后的句子，请求体里不出现「请判断是否冲突」。

不采用「引擎用关键词宣布结论冲突」。那仍是词表，不是干涉。

### 8.2 第一闭集三条，称谓有条件，定义项不进

| 稳定子    | 判定                                                          | 失败后                                      |
| --------- | ------------------------------------------------------------- | ------------------------------------------- |
| S1 引用   | 引用标识属于本轮来源包；`demoCorpus` 不得写成权威源           | 只重做该引用因子，至多 2 次，然后【待核实】 |

| S3 修订轨 | 空修订轨、整句删加整句增，不得当作完成（沿用现有 `xml_qa_*`） | 只重做该次改稿                              |

S4 当事人称谓先不进闭集。只有案件档案或文书当事人栏里已经有规范名、且可以用确定性字符串对齐时才启用；对不齐就记 \(+1\)，不调用模型猜。定义项全图留到阶段 D 的边，不塞进第一批稳定子，避免变成文风禁令。

### 8.3 骨架按任务自动选，不问律师

1. 本轮是在改已有文稿：骨架就是该文稿。绝热步是手术改，不是另起一篇。
2. 否则意图已经落到有内置母版的交付类型：骨架用该母版。
3. 否则允许这一次自由生成。稿头标明「未从已验证骨架变形」。稳定子照常测。不暂停，不让律师选母版。

### 8.4 改一处只重修光锥

律师指出稿中一处不对：撤销触及该锚的写，重采样该因子及其 1-hop，只复查这些因子的稳定子，至多 2 次。仍失败则只有这一处【待核实】，其余保持。因子图还没有时，光锥退化为同一条款、同一批手术改。不整篇重测。

先做因子记录、纯度和 S1–S3。干涉、约化、光锥、同伦都读这个对象；对象不存在时，后四段都会变回提示词补丁。长文多副本合并不早于阶段 D，也不插到 A 前面。

这五条已确认。工程从阶段 A 起的运行时已接入；后续只在这条合同上加厚，不另开计划模式或 Skill 配置。加厚的科学边界是 §9，不是再把 A→E 的名字做厚。

## 9. 科学裁决：六类缺陷、量子启发、硬件与模拟器

> 2026-10-02 写入。本节约束因子态与测量纪律的后续优化。§1、§8 的律师侧拍板不在本节重开。§4 至 §8 里已经接入的钩子继续有效，直到被按本节改写成满足 §9.3 的结构。二者冲突时，下一轮代码以本节为准。

### 9.1 两个对象

量子计算，指在希尔伯特空间上做酉演化并用相位干涉取得经典算法没有的资源优势。对角态

\[
\rho=\sum_i p_i\lvert i\rangle\langle i\rvert
\]

里相位已经消失。合同写明不存相位、不跑线路，就是放弃这一块资源优势。在这个近似下，量子计算机相对经典概率没有还没被用上的算子。

量子启发，指借用量子信息里在对角态上仍然成立的规则，写成经典状态机：混合态与纯度、独立证据的逐点乘积、非破坏的综合征、部分迹、延迟到交件才做的投影、交件前的可逆补丁。这些规则在因子图、贝叶斯网络和可逆编辑日志里本来就有。量子语言把它们收成同一套态，不提供新的复杂度。

因此产品路径是：用对角量子态的语法重写 agent 的状态与测量。量子计算机不重写 agent。

### 9.2 六类缺陷各自能被什么压住

| #   | 缺陷                 | 能压住它的结构                                                                                                                                                               | 科学边界                                                                         |
| --- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 1   | 自回归锁死           | 态是锚上的 \(\rho_i\)，模型只提议局部更新；错了走光锥逆运算，不顺着错误前缀圆                                                                                                | 自回归本身不可解。测量之后的稿是经典字符串。可消除的是「把采样轨迹当成世界状态」 |
| 2   | 局部流畅冒充全局成立 | 中间表示上的一组只读、确定性、互不干扰的稳定子；失败只修综合征触到的因子                                                                                                     | 检查器必须是可机器判定的事实。文风判断不是稳定子。检查频次要高于错误积累的速率   |
| 3   | 不确定写成确信       | \(\gamma_i=\sum_o\rho_i(o)^2\ge\gamma^\star\) 才写成确定句；否则混合态，禁止 \(\arg\max\)。独立证据按 \(\rho'(o)\propto\rho(o)\sigma(o)\) 融合；支撑不相交则冲突，两侧都留下 | \(\rho_i\) 必须来自可寻址锚上的独立证据。质量恒为 1 时，纯度门槛不做决定         |
| 4   | 上下文被当成真相     | 子工输入是因子图上距离 \(\le 1\) 的边际，父会话其余历史不进入                                                                                                                | 没有边就没有迹可求。丢掉父对话只是隔离，不是约化。被丢掉的长程边就是近似误差     |
| 5   | 生成不可逆           | 交件前每笔写带逆运算；律师改一处只撤销光锥内的写并局部重采样；外发与删除案件才是不可逆测量                                                                                   | 没有补丁逆元，光锥只是拒绝下一笔写                                               |
| 6   | 自己的话喂回自己     | 交件前内部读法保持未测量；证据通道只接受带 span 的工具结果；综合征触发后只重采样触到的因子，失败散文不保留为下一轮的事实                                                     | 把失败散文和修复提示追加进同一条对话，就是这条缺陷本身                           |

缺陷 (2)(3)(4)(5)(6) 可以在结构上被禁止或被局部化。缺陷 (1) 只能被绕开：态不放在自回归轨迹里。没有证据表明量子采样器在法律长文上比经典语言模型更能保持全局一致。那是模型与数据问题，不是计算模型问题。

### 9.3 可检验命题

设交件态为稀疏因子图上的对角分布 \(\{\rho_i\}\) 加纠缠边；模型是对该图的局部提案机；稳定子是图上的确定性综合征；融合是独立证据的乘积；子工输入是 1-hop 边际；写是带逆元的补丁；唯一的投影测量是终稿以及外发。则缺陷 (2) 至 (6) 被结构压住，缺陷 (1) 被绕开。

这条命题相对主流 ReAct 改变的是状态放在哪、何时允许投影、谁来判定冲突。它不改变 `runTurn` 的采样循环。采样循环保留。

命题成立要同时满足三条，缺一则本轨道的改动不算完成：

1. **校准。** \(\rho_i(o)\) 不是恒为 1 的标签。最低层是「有独立 span / 没有」。在有标注的小集合上，才允许用可靠性估计代替这层二元质量。\(\gamma^\star=0.75\) 在质量恒为 1 的数据上不得当作门禁。
2. **覆盖。** 稳定子闭包盖住引用、金额与期限、定义项、当事人称谓、修订轨这几类机械错误。盖不住的法律判断仍归模型，并允许以混合态交件。
3. **消融。** 在固定任务集上，只计五类错误：引用不在来源包、金额与计算器不符、定义或称谓漂移、修订轨空或整句替换、没证据的句子写成事实。新结构必须优于「同一个 `runTurn`，只在压缩后把这五条不变量重注进提示词」。优不过，量子叙事从本轨道撤下，只保留赢了的检查器。

任务集未建立时，不得宣称六类缺陷已被解决。无夹具则跳过，不以合成句代替。

### 9.4 已接入钩子与命题的差距

下列事实是后续优化的起点。补这些差距，不新增原语名字。

### 9.5 量子硬件与模拟器

交件回合禁止调用量子处理器、厂商云量子接口、以及为了相位而跑的线路模拟器。理由如下。

近端含噪声器件的稳态更接近对角混合态，而不是相干叠加。合同已经在 CPU 上精确计算这个对角态。噪声不会把删掉的相位还回来，它把相位毁掉。把量子处理器放进 `runTurn`，不能在这六类缺陷上超过精确的对角更新。

本问题的规模与结构也不提供已知的量子优势：

- 锚是稀疏符号（条款、定义、金额槽、引用 span），不是已知谱的哈密顿量。
- 因子图按设计就是少边、低树宽。低树宽上，联结树与置信传播可以精确或近乎精确；约束求解（CP-SAT 一类）是稳定子满足问题的强制基线。QAOA 与量子退火要显示优势，需要高树宽或无结构搜索。产品把图做成稀疏，就是拿掉这些算法的适用条件。
- Grover 相对无结构搜索至多平方加速。法条与案例检索有倒排索引、引用标识和向量索引。有结构的索引优于无结构的 Grover。
- 幅度估计对「可装入量子电路的期望」有平方加速（Brassard、Høyer、Mosca、Tapp）。`calculate` 是闭式规则，经典算术精确，优于蒙特卡洛，因此也优于幅度估计。只有将来出现无法闭式求解、又贵的程序树期望（例如昂贵的诉讼分支期望）时才重新评估，并且基线是经典多层蒙特卡洛，不是量子接口。
- 退量子化（Tang，STOC 2019）与「数据的力量」（Huang 等，Nature Communications 2021）说明：在同样的数据访问假设下，许多量子机器学习提议有经典对应物；量子核要赢，需要经典模型难以模拟、且数据贴合那个特征映射。法律锚不满足这个前提。
- 容错时代与「全局一致抽样」问题陈述最接近的算法是量子吉布斯采样。它仍以局部哈密顿量的经典后验已经存在为前提。低树宽下精确推断使它没有产品位置。不把交件路径规划到容错硬件上。
- 量子纠错保护的是量子比特，不是引用和金额。上下文压缩是经典信息丢失。不要用硬件纠错码去修压缩。
- 经典影子（Huang、Kueng、Preskill）用来估计一个已经存在的量子态的许多观测值。本系统没有那个态。稳定子是直接求值的确定性函数。

模拟器只允许作为离线研究脚本，不进入回合，不阻塞交件，不对律师暴露。允许的唯一实验：

1. 冻结不超过 16 个二元锚的玩具案件，有已知的一致赋值和已知冲突。
2. 预先写明胜出幅度，再跑实验。指标是确定/混合判定的 Brier 分数或对数损失，以及压缩噪声（随机丢掉一部分证据记录）之后的稳定子违反率。
3. 三方对照：对角乘积；联结树或置信传播；键维很小的矩阵乘积态或不超过二十个量子比特的态矢量（相位只出现在第三方）。
4. 第三方若未超过预先写明的幅度，相位继续禁止进入产品。键维必须很大才能拟合时，优先补经典因子图上缺的边，而不是换成量子处理器。
5. 态矢量再大就用张量网络模拟器（研究依赖，不进桌面包）。不调用厂商量子云。

DisCoCat / 范畴组合语义（Coecke 一系；lambeq 一类张量收缩）是量子自然语言处理里最严肃的研究线。它可以在模拟器上对短句做蕴含测量。它需要文法和训练好的函子，替代不了采样模型，也不进引擎。Born 机与神经量子态若要试，只能占用上面同一个实验槽，不得单独开一条产品路径。

在任何模拟器实验之前，缺陷 (3) 的校准优先采用保形预测：预测集大小为 1 才允许写确定句，否则渲染为【待核实】。它给出有限样本覆盖保证。未校准的纯度是这条规则的弱代替。

### 9.6 后续优化顺序

一次只做一步。每步写明压住 §0.1 的哪一条，并带假模型也能跑的测试。触及编排、并行或门禁时，仍要真循环 cassette。

1. 证据记录：锚上的质量至少分成「有独立 span / 没有」。禁止再把活路径质量恒写成 1。
2. 中间表示成为会话状态。模型提交补丁，对话降为提案日志。`runTurn` 保留。
3. 稳定子改读中间表示。失败只重采样触到的因子，失败散文不写回事实通道。
4. 边在抽取时写入。子工查询 1-hop。融合键是节点 id，模型可以提议「两句是同一节点」，引擎核对 span。
5. 补丁日志带逆元。光锥是依赖边的闭包；闭包未一起更新则整批零写入；撤销是逆补丁。
6. 骨架是模板语法树或上一份已通过综合征的中间表示。每步只绑定本步的新槽，步数仍不超过 6。实现：`parseSkeletonForest` / `bindSkeletonSlot` / `commitPassedSkeleton`（`src/lawmind/agent/skeleton-tree.ts`、`factor-state.ts`）。标题仍只是可改起点，不锁句子。
7. 建立 §9.3 的任务集并做消融。未胜出则停。行业夹具消融在 `src/lawmind/agent/factor-state-legal-industry-ablation.test.ts`（与协议单测共用 `factor-state-legal-industry-fixtures.ts`）。未胜出不得写成六类缺陷已解决。
8. 只有第 7 步胜出、并且能量化 1-hop 丢掉的长程边造成的错误之后，才允许做 §9.5 的离线模拟器实验。测量在 `hopTruncation`。离线三方对照在 `src/lawmind/evaluation/offline-diagonal-simulator.ts`：对角乘积、≤16 锚点精确成对边际（联结树金标）、相位混合。预先写明 `PHASE_BRIER_WIN_MARGIN`；本夹具上相位未胜出，不进产品、不进 `runTurn`。保形门在 `factor-conformal.ts`。硬件不在本顺序里。几个量子比特的内核也不在本顺序里，理由见 §9.7。

律师向内核评测的标准、链接、加题方法和跑法见 [LAWMIND-LEGAL-KERNEL-BENCH.md](./LAWMIND-LEGAL-KERNEL-BENCH.md)。夹具 ≠ 官方 CUAD 全量，≠ 律师打分真稿。

回复保留模型的判断，只在有冲突或未接地的机械项下附上【机械核定】。这笔冲突在同一条回复里收口，不再另开修复采样。已有标题写成【骨架起点】，写明可改、可增、可删。律师说「不对」之后，下一次渲染读恢复后的草稿，不把写作中途的文本冻成 Word。检索原文抄进因子，采样不再重复送命中包装。定义环只标待核实，不选边。夹具计数是基准 21、现在 0。

这三件做完之后，这条轨道上还没有、也不再靠锁死模型去补的，是把整段对话换成案件中间表示。骨架已是编号大纲语法树加上一份已通过综合征的中间表示。机械项已经以因子为准，散文判断仍留给模型。引用检查认《法律》第 N 条和法释字号，金额检查认「元 / 万元 / 千分位」，同额不记冲突，检索之前不把模型自己写的法条收成冲突。律师向套件还要求：错金额从下一轮采样前缀撤掉但律师可见回复仍保留判断句；核定附注不得吞掉「建议主张解除」这类表达；结构提纲与或然口径（「若…则…」「宜写两种路径」）不得被标成机械冲突。夹具仍不是律师打分的真稿，不能据此保证每一份真实交件都更好；它能说明的是：在这些律师会改的机械项上 treatment 优于 plain 与提示词重注，且没有用锁死表达能力换机械分。

几个量子比特的内核不会在这些夹具上更好，也不嵌入 `runTurn`。

单量子比特写在计算基上时，相对相位 \(\phi\) 在测量概率里消去：

\[
p_0\cos^2\phi+p_0\sin^2\phi=p_0.
\]

所以一个比特的相位不改变对角规则已经给出的概率。

两比特上，乘积融合已经把非法联合读法的质量设为 0。再用未校准的振幅 \(\sqrt{\varepsilon}\) 把它混回去，非法读法的概率变成 \(\varepsilon\)，只升不降。测量必须返回一个比特，对角规则返回的是「冲突」；强迫返回比特，就是再次 \(\arg\max\)。

因此：小比特内核要么复述对角分布，要么把已经判成混合的冲突重新塌成一句。两种都不是奇效。§9.5 的离线实验仍然排在第 7 步消融胜出之后，而且那个实验的对照里包含「相位没有赢」。

### 9.8 六缺陷能力测验（主张 Q）

2026-10-04 写入。量子启发要对齐的是 §0.1 六类缺陷与铁律 5（发挥模型能力），不是机械五类分数板。§9.3 / §9.7 的消融与律师向套件是**否证门**：过不了则撤叙事、只留检查器；过了也不得写成「模型变强」或「真实交件更好」。

**主张 Q。** 在同一套假模型脚本下，对照三臂——plain（无因子态，散文整段进下一轮前缀）、reinjection（压缩后只重注五句不变量）、treatment（当前因子态）——对下表每一题，treatment 必须同时：

1. 压住或绕开该题对应的 §0.1 缺陷（结构胜利）；
2. 仍保留判断句与写作/检索工具广告（表达未锁）；
3. 相对 plain / reinjection，下一轮请求体更少被错误前缀绑架（能力放大）。

结构分与表达分**双轨计分**，禁止合成一个「量子分」。任一条结构性题 treatment 不优于 plain，该题记失败；对应原语降级为「仅检查器」，不得用机械套件分数掩盖。
