# C. 风险最高的 10 个硬编码值（审计者视角）

1. **`credential(clientId) = HMAC(installationSecret, clientId:epoch)`**（local-api-auth + local-api-credentials）——回环 API 全部客户端凭据的派生式；改算法或丢 secret = 所有客户端（含 Word 窗格）立即 401，且 secret 本身被 7 层 deny-list 保护不得入子进程。
2. **`midTurnCompactTriggerRatio = 0.9` + `warnRatio = 0.85`**（context-tuning.ts:144-145）——上下文压缩触发线；调高→溢出丢回合，调低→摘要失真变笨。曾有测试用 env 压到 0.02 强制触发。
3. **`HISTORY_QUALITY_CONTEXT_TOKENS = 200_000`**（context-budget.ts:31）——1M 窗口也按 200K 管历史质量带；以为「窗口多大历史就多大」会踩坑。
4. **`LAWMIND_SKIP_API_AUTH` / `LAWMIND_ALLOW_DANGEROUS_TOOLS_WITHOUT_APPROVAL` / `LAWMIND_ALLOW_CHECKLIST_BYPASS` / `LAWMIND_ALLOW_RENDER_GATE_BYPASS`**——四个 dev 绕行开关；SKIP_API_AUTH 仅在打包构建被显式忽略，其余三个**打包内仍生效**，属「dev 便利、生产炸弹」。
5. **`LEGAL_GUARDIAN_MAX_ROUNDS = 2`**（guardian/types.ts:8）——独立审稿 2 轮不过即交律师；调大看似「更努力」，实测是「为过审而改稿」的退化开关。
6. **`DEFAULT_AGENT_MAX_TOOL_CALLS_PER_TURN = 80`（且服务端 clamp 80）**（workspace-policy.ts:710）——软顶 80、硬顶 80 相同；env 想调小做保守部署容易，想调大**根本调不动**（clamp）。
7. **诉讼费 10 档费率表**（litigation-fee.ts:32-43）——唯一带版本锁（`LITIGATION_FEE_VERSION=1`）与生效日的表；SECURITY.md 明确「错误的法定参数比没有规则更糟」，改它必须留痕，属全仓库最高法律风险字面量。
8. **`REVIEW_MODEL_TIMEOUT_MS = 480_000` vs 默认 120_000**（capability-envelope.ts:35）——draft/review 任务静默享受 4 倍超时；把 `LAWMIND_AGENT_TIMEOUT_MS` 当全局唯一超时会误判 review 卡顿。
9. **`SAFE_COMMAND_LOADER_ENV_DENY`（17 项加载器钩子）+ 密钥前缀 18 家**（safe-command.ts:128-156）——子进程环境的最后防线；`extra` 显式授予也穿不透，唯一例外是 MCP 的 `LAWMIND_MCP_SECRET`（mcp-client-bridge.ts:102）。
10. **`IDENTICAL_TOOL_REPEAT_NUDGE_AT = 3` / discovery 总帽 8→32 伸缩 / host 文件硬帽 48**（model-loop + tool-pipeline + host-policy）——防死循环的三道闸，全部按 `contextTokens` 伸缩而非固定值；以为是固定小数字会在大窗口模型上误判「模型变笨」。
