## 2. Wave 1 — Compact / 记忆看得见（优先）

### 目标

长会话 compact 后，模型不只看到「关键词摘录」，还能看到**连贯摘要**；律师操作 compact 前有预期；巨型 tool JSON 不再吃光窗口。

### 2.1 A1↑ — Compact LLM 再摘要（可选增强）

| 项           | 内容                                                                                                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **现状**     | `buildDroppedSpanDigest` 提取式；无额外模型调用                                                                                                                      |
| **要做**     | compact 前对 `droppedSpan` 调一次短摘要（同 agent 模型，`taskKind: classify`，低 `maxTokens`）；成功则替换/拼接提取式 digest；失败回退提取式                         |
| **代码点**   | `src/lawmind/agent/compact.ts`（或新建 `compact-llm-digest.ts`）；`autoCompactSessionHistory` 可选 `async` 路径，或桌面/手动 compact API 先异步、turn 内仍同步提取式 |
| **建议策略** | Turn 内默认仍提取式（零延迟）；**手动** `POST …/compact` 与 compose「整理上下文」走 LLM 摘要                                                                         |
| **验收**     | 单测：mock model → digest 含「摘要：」；失败路径不抛、仍有提取式；费用可关：`LAWMIND_COMPACT_LLM=0`                                                                  |
| **工时**     | 1.5–2 人日                                                                                                                                                           |

### 2.2 A10 — Distill 待采纳预览回灌

| 项         | 内容                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------- |
| **现状**   | `compact-distill` 只写 pending adoption，模型默认看不见                                                     |
| **要做**   | compact/distill 后，本轮 system note 注入只读块「待律师采纳的偏好/案件要点（预览）」；**不**静默写入 MEMORY |
| **代码点** | `compact-distill.ts` + `prepareTurnPromptContext` 或 compact 后 system 附件                                 |
| **验收**   | distill 后下一轮 prompt 含预览；采纳前后行为不变                                                            |
| **工时**   | 0.5–1 人日                                                                                                  |

### 2.3 F4 — Compact 前预览 UI

| 项         | 内容                                                                          |
| ---------- | ----------------------------------------------------------------------------- |
| **现状**   | Compose 有 compact 动作，无「将移除 N 条 / M tokens」                         |
| **要做**   | 点击整理前弹确认：估算将移除消息数、估算 token、是否 LLM 摘要；确认后再调 API |
| **代码点** | `LawmindComposeContextUsage.tsx` + sessions compact API 可选 `dryRun`         |
| **验收**   | e2e 或组件测：dryRun 不改 history；确认后 compacted=true                      |
| **工时**   | 0.5–1 人日                                                                    |

### 2.4 A9 — Tool 结果超阈值摘要

| 项         | 内容                                                                                                                             |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **现状**   | tool result 整段 `JSON.stringify` 进历史                                                                                         |
| **要做**   | 写入 session 前：若估计 tokens > 阈值（如 4k/8k），保留 `ok/error` + 关键字段，正文截断并标记 `truncated:true` +「可用工具重读」 |
| **代码点** | `session.ts` 写 tool 消息处；或 `turn-orchestrator-tool-round.ts`                                                                |
| **验收**   | 超大假 tool 结果历史长度有上界；模型仍见 ok/error                                                                                |
| **工时**   | 0.5–1 人日                                                                                                                       |

**W1 DoD**：手动 compact 可选 LLM 摘要；distill 预览进 prompt；UI 有预览；大 tool 结果不爆窗。
