# Solo：5 分钟合同审查（试用短路径）

> 目标：律师从打开 LawMind 到可签批意见书，尽量 ≤2 次关键跳转。  
> 对齐三条铁律：**上手简单**（短路径）· **交付质量高**（仍经签批/验收）· **稳定性高**（同一套立场×深度口径）。  
> 对标商业入口：立场（中立 / 委托方 / 相对方）× 深度（快速 / 标准 / 深度）。  
> 闭环目标（商业入口 ≈8.5）：拖入/送审 → 交办 →「去签批」→ 自动导出 Word → 可选审阅稿。

---

## 一句话路径

**引用合同 → 选立场与深度 → 开始审查 → 去签批（在办）→（默认）导出 Word → 可选审阅稿。**

---

## 三步试用话术

1. **打开合同**
   - 对话空态「5 分钟合同审查」，或
   - 文件台对 `.docx` / `.doc` / `.pdf` 右键 / 编辑器「送审本合同」，或
   - 从文件树拖入对话输入区（有消息时出 compact 短路径卡）。

2. **选口径**
   - 立场：中立 / 委托方 / 相对方
   - 深度：快速（3–5 个关键风险）/ 标准 / 深度
   - 点「开始审查」交办（写材料填表路径同芯片）。

3. **签批与导出**
   - 对话点「去签批」进入「在办」；通过后默认自动导出 Word。
   - 需要对照改稿时点「导出审阅稿」。

---

## 首跑提示

- 文书类型列表优先展示「合同审查意见」。
- 选合同审查时种子交办**不含「先计划」**，权限直接「标准」可执行，避免 Day-1 卡死。

---

## 不要对外承诺的边界

- 仍须律师签批；自动导出不等于免审。
- 深度审查可升完整专案组，不是 Word 插件内嵌改稿。
- 完整审计链 / DFA 是差异化能力，不在「5 分钟」话术里展开。
