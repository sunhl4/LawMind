# Word 改稿要点（权威口径稿 · v2）

钉选 Word 并点选类型后，引擎把对应文件注入现有「拷贝原件 → 字级修订 → 旁路导出」回合。不是第二条改稿流程。

每条四格：**看**（这类稿的标准检查位）· **改·甲方/乙方**（该立场下的通常处理）· **停**（非法、无效或须客户确认）· **透**（规范依据，不是必须强制写入合同正文）。

## 口径层次（比个人经验稿更稳）

1. **制定法优先**
   - 股权：2023年修订《公司法》（第47/54条出资期限与加速到期、第57条知情权、第88条转让出资责任、第89条压迫救济、第224条减资）
   - 采购：《民法典》买卖、检验、风险、定金、格式条款、免责无效、产品责任、所有权保留
   - 用工：《劳动合同法》《社会保险法》《劳动法》工时
2. **司法解释与司法文件次之**
   - 《九民纪要》第5条：与目标公司对赌原则有效，履行受资本维持 / 减资限制（法〔2019〕254号）
   - 法答网精选答问第九批（2024-08-29）：回购权未约定行权期的，合理期间以不超过6个月为宜
   - 法释〔2024〕11号：大型企业与中小企业间的「背靠背」付款条款无效
   - 法释〔2024〕15号：《公司法》第88条第1款不溯及2024年7月1日前的股权转让
   - 《劳动争议司法解释（一）》第36条：未约定竞业补偿时，离职前12个月平均工资的30%，且不低于最低工资
   - 《劳动争议司法解释（二）》（法释〔2025〕12号，2025-09-01施行）第10/12/13/19条：连续二次认定、特殊待遇服务期赔偿、竞业与秘密相适应、不缴社保无效+经济补偿
3. **行政法规与监管文件**
   - 《保障中小企业款项支付条例》（2025修订，2025-06-01施行）第9条：大型企业60日付款、禁止第三方付款前提
   - 人社部2025年《企业实施竞业限制合规指引》：合规导向，不是裁判依据
4. **行业示范与比较法，不替代中国法**
   - NVCA Model Legal Documents：市场默认多为1×非参与优先清算、broad-based weighted average 反稀释、保护性条款
   - 汉坤等境内/境外交易文件结构对照：优先清算、否决权须落到章程才较易对抗公司与后加入股东
5. **审查方法论（教材与公开课的共同骨架，不是某位朋友的习惯）**
   - 吴江水《合同审查的结构与方法》《完美的合同》：主体 → 标的 → 价金 → 履行/验收 → 责任
   - 《民法典》第470条/原《合同法》第12条一般条款与此同构

## 覆盖层规则

- 工作区有这些 `.md` 时优先用这里的版本；没有则用引擎内置稿。
- 文件头的 `<!-- word-revision-pack:vN -->` 是版本戳：低于引擎内置版本时，律师改写的条目保留，**内置新增条目会自动并入**，避免旧稿盖住新法。
- 不要写入具体案件机密。
