# Vision (LawMind)

LawMind is a **local-first lawyer workbench**: task-driven work, reviewable deliverables, and clear audit boundaries—not “chat for its own sake.”

**Three non-negotiables** (lawyer product): (1) **easy to start**, (2) **high deliverable quality**, (3) **stable, predictable delivery**. Chinese source of truth: `GOALS.md` §二 + `docs/LAWMIND-VISION.md`（律师产品三条铁律）.

Authoritative narrative, phases, and product principles live in **`docs/LAWMIND-VISION.md`**. Architecture and runtime shape: **`docs/LAWMIND-ARCHITECTURE.md`**.

## Engineering norms (short)

- One PR ≈ one issue or coherent topic; avoid unrelated drive-by edits.
- Prefer evidence: failing test, logs, or traced code path for bugfixes.
