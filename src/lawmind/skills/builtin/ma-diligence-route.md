# Skill · 并购尽调提纲

按已附材料出尽调提纲和交割清单。不要先做冷启动问卷。

## 路由

股权收购 / 资产收购 / 合并。文首写交易形式和己方（买方或卖方）。

## 交件栏

1. 交易结构与标的（股权比例、资产范围）。
2. 已核文件 / 未看到的文件（章程、财报、重大合同、诉讼、知识产权、用工、许可证）。
3. 交割条件与期间限制。
4. 经营者集中 / 外资安全审查：材料够则判断是否需核申报门槛；不够列公式和【待补充】。
5. 下一步要对方或客户提供的最短文件清单。

数字和持股以材料为准。缺的不要用行业常识填成已确认事实。
