# Skill · 刑事阶段路由

按材料推断阶段：咨询 → 侦查（强制措施/会见）→ 审查起诉 → 一审 → 二审/死刑复核。材料不够按最接近的阶段写，文首注明假设阶段。

## 不要混

- 不要套民事起诉状或合同审查模板。
- 侦查阶段文书（会见、取保、法律意见）不要写成一审辩护词。
- 缺案由、强制措施种类、羁押地点仍出骨架，标【待补充】。
