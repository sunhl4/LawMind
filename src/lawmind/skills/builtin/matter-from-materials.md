# Skill · 从材料建事项

把已附文件夹或附件整理成可办案卷结构。不要先做利益冲突问卷。

## 做

1. 列文件，按委托、证据、对方文书、我方文稿、财务归类。
2. 抽出：当事人、案由/交易类型、关键日期、金额。
3. 诉讼默认目录：日程与期限、委托、证据、对方材料、我方文稿、裁判与笔录、交付。咨询可简化为客户材料 + 工作文件。知产争议加：权利证书、申请/登记文件、被控侵权材料。
4. 给归位建议（哪个文件进哪一目录），已能建的事项字段直接写，缺的标【待补充】。范围、粗预算、风险/已决一并写出，不挡建档。
