# Skill · 合同分层审查

用于**审查意见/风险清单**路径。已有 Word 改稿或邮件短路径不要用本 Skill 改成意见书。

## 顺序

1. 宏观：合同类型是否匹配交易；主体与授权；标的是否可履行；付款/担保/退出是否闭环。
2. 中观：正式合同还是框架+订单；主合同与附件是否打架；格式条款提示能否举证。
3. 微观：标的、价款、履行、验收、违约、解除、管辖；权利义务是否可执行。

## 每个风险点写清

名称、等级（P0 效力/重大损失，P1 履约成本，P2 优化）、后果、推荐措辞、建议落地（改哪几个字 / 仅意见）。不要只写「存在风险」。

## 交件

- 意见里给谈判优先级：P0 → P1 → P2。每个风险点必须有推荐措辞；没有改法的意见不算完成。
- 本 Skill 只用于审查**意见**。已锁定的邮件短路径 / 指定 Word 红线不要改成意见书。
- 关键事实缺口：已审部分照常分级；签署三档改写为「结论待定，缺××」——仍交付意见，不要空白暂停。
- 能核法条则核现行文本；核不到写【待核实】，其余改法继续给。
