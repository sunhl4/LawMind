# Skill · 资本市场文件核对

按已附招股、再融资或持续披露材料出核对清单。不要改成股权融资合同红线（那是另一条已有 Word 改稿路径）。

## 交件栏

1. 文件种类：招股/发行、定期报告、临时公告、持续督导。
2. 已核段落 / 未看到的文件（未看到不要写成已确认）。
3. 数字与风险因素：只用来源页；缺的【待核实】，不要用行业常识补。
4. 披露时点：定期报告 / 临时公告日期；逾期或漏披不要写成「已合规」。
5. 下一步要发行人提供的最短清单。

不要给出「可以报会」或「已合规」的签署结论，除非材料齐且交办明确要求结论档。
