# Skill · 劳动解除分流

来源方法学：`pa1nrui1/legal-skills`（MIT）的劳动规则回放；本文件为独立重写，不复制其文案。规则数值仍以现行法与当地口径为准，未经法律顾问验收不升为硬闸。

## 先定解除类型，再选计算种类

| 常见情形                                             | 计算种类      | 必须先核对                                       |
| ---------------------------------------------------- | ------------- | ------------------------------------------------ |
| 用人单位提出协商解除                                 | N             | 谁先提出、协议怎么约定；员工先提出时不一定有补偿 |
| 第 40 条预告解除（医疗期满、不能胜任、客观情况变化） | N+1           | 是否提前 30 日书面通知；未通知才有代通知金       |
| 第 39 条过失性解除                                   | 0             | 违纪事实、规章制度、送达与申辩记录是否成立       |
| 第 41 条经济性裁员                                   | N             | 是否履行法定程序、是否优先留用                   |
| 违法解除                                             | 2N            | 解除依据是否成立；劳动者是否要求继续履行         |
| 合同期满终止                                         | 视情形 N 或 0 | 是否属于第 46 条应付补偿的情形                   |

三条硬线：

1. **2N 与 N+1 不叠加**。违法解除按 2N；不要写成 2N+1。
2. **协商解除不默认有补偿**。谁提出、协议怎么写，决定有没有 N。
3. **过失性解除不默认 0 风险**。先核对事实、制度、送达；证据不足时标【待核对】，不要直接写 0。

## 计算口径

- N：每满一年一个月；六个月以上不满一年按一年；不满六个月按半个月。
- 月工资：解除前十二个月平均应得工资；高于当地社平三倍的，按三倍计，年限最高十二年。
- N+1：只有符合代通知金情形才加一个月；不是所有解除都加。
- 2N：按上述 N 的两倍；不再叠加代通知金。
- 加班费：工作日 150%、休息日 200%（无补休）、法定假 300%。
- 双倍工资：未签书面合同的期间限制按材料算；缺期间列公式，不填假数。

金额必须调用 `calculate` 的 `economic_compensation` / `overtime_pay` / `double_wage`。模型只填槽，不口算。

## 材料清单

解除通知书、劳动合同、工资流水或工资表、社保记录、考勤/加班记录、规章制度与签收、工作年限证明、协商协议或会议纪要。缺哪项就写【待补充】，不要用推测值代替。

## 交件口径

表格列：项目、解除类型、公式、数字、依据条文、缺口。结论区分「已算清」和「待补材料后才能定」。仲裁前置与时效另用 `calculate`（`legal_period`），不要挡已经能算的金额。
