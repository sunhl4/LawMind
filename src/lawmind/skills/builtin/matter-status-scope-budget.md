# Skill · 办案状态：范围变更与预算

`matter-status-report`（办案周报）负责一页状态；本 Skill 补上项目管理里律师真正会被追问的两件事：
**范围有没有变**、**花掉的钱和时间对不对得上**。

来源方法学：legalopsconsulting/lpm-skills（Apache-2.0）的接案→范围→预算→期限→状态报告闭环；
本文件为独立重写，不复制其文案。

## 什么时候用

- 交办说「出周报/月报/状态报告」时，在 `matter-status-report` 骨架之上补本节两栏。
- 交办只说「范围」或「预算/工时」时，只出对应那一节，不必凑整份周报。
- 结案备忘、资源计划、沟通计划仍走各自既有口径，不并入本节。

## 一、范围变更登记

每条变更一行，四要素缺一不可：

1. **变更内容**：从什么变成什么。
2. **触发**：谁在什么时候提的（客户/对方/法院/我方）。
3. **对预算与期限的影响**：增加多少工作量、是否影响关键期限；说不清就写【待估】。
4. **状态**：已确认 / 待客户确认 / 我方内部判断。

范围**未变**时也要明写「本期无范围变更」，不要留空——空栏会被读成「还没做」。

不要把范围变更写成新的委托事项，也不要据此自行调整费率或报价。

## 二、预算与工时对照

- **已发生**：按阶段（接案/检索/起草/审阅/出庭）列工时或费用项；有台账用台账，没有写来源。
- **对照**：预算 vs 已发生 vs 剩余。只有工时没有费率的，列工时项并标【缺费率】。
- **偏差**：超出预算阈值时如实写偏差与原因；不含推测性「预计还能省」。
- 金额能算则用 `calculate`，不要口算；缺流水或台账的标缺口，不编数字。

## 交件口径

- 本稿是内部管理件，不对外签发；客户版摘要按交办单独出。
- 进度仍写结果不写活动（与周报一致）：开会次数不是进度。
- 下一步必须带日期；缺日期标【待补日期】。
- 缺预算台账时不空转：出范围变更 + 工时骨架，并在缺口处标明缺什么。
