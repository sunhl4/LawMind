# Skill · 知产争议路由

按材料推断：权利基础 → 被控行为 → 行政/民事/海关路径。文首写权利种类和程序。缺证书仍出骨架，标【待补充】。

## 目录（知产争议）

权利证书、申请/登记文件、被控侵权材料、对比说明、程序文书。

## 不要混

- 不要把专利侵权写成借款纠纷起诉状。
- 商标异议/无效与侵权诉讼分清。
- 对比表用线性栏目（权利特征 / 被控特征），不要 markdown 表。
- 能检索则核权利稳定性和类似案例；不能则【待核实】仍给对比框架。
