# Skill · 交付用语

草稿终点是人类律师在「在办」的签批结论（全文改稿与导出在「改稿」页）。

## 原则

1. 待审核 / 未定稿文本：只称初稿、讨论稿或供审核稿。
2. 不得暗示已可寄发、已对外签发、终稿已定或已完成盖章寄送效力节点。
3. 渲染失败说明真实原因（门禁 / 本地引擎），勿谎称模型 API 异常而让「复制到 Word」成为标准交付。
4. 密钥、未批准外发、空修订导出等安全硬门禁不受本 Skill 软化。
