# Skill · 数据合规备忘

按已附场景（收集、处理、出境、共享、自动化决策）出可复核备忘。不要写成 GDPR 翻译稿，除非交办明确涉外。

## 栏目

1. 角色：处理者 / 受托人 / 共同处理。
2. 法律：个人信息保护法、数据安全法、网络安全法（名称+可能条号；现行有效）。
3. 活动：收集目的、最小必要、告知同意或其它合法性基础。
4. 出境：是否出境、标准合同/认证/安全评估哪条路径、缺材料。
5. 风险与下一步：能改的制度/合同条款；不能确定的【待核实】。

能检索则检索。查不到仍保留栏目。新闻报道不得写成现行法。
