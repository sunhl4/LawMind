# Skill · 家事继承路由

按材料推断：离婚（冷静期/财产/子女）→ 抚养探望 → 继承（遗嘱/法定/遗赠扶养）。文首写程序。缺财产清单仍出骨架，标【待补充】。

## 交件栏

1. 程序阶段。
2. 争点（程序与实体分开）。
3. 请求：子女利益与财产分栏。
4. 证据与对方抗辩。
5. 能算的期限用 `calculate`。

## 不要混

- 不要写成民间借贷或买卖合同纠纷。
- 子女利益单独一栏。
- 财产单独一栏，不要和抚养探望混写。
- 继承：先确定继承人范围和遗产范围，再谈分割。
