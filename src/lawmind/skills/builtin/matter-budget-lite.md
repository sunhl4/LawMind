# Skill · 事项范围与预算

接案整理时顺带写出范围，不要先填冲突表或预算审批。

## 交件栏

- 范围：本次要交的文书/程序（已能确定的）。
- 不在范围内：明确排除，避免悄悄扩大。
- 期限：已知的开庭、答辩、申报截止。
- 预算：按小时或按件的粗估；缺费率标【待补充】，仍给工作项列表。
- 置信：已确认 / 从材料推断 / 未知。范围变更单独一行，不挡建档。
