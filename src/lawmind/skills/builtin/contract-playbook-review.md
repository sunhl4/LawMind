# Skill · 合同 Playbook 审查

审查合同的第二层口径：不只看「有没有问题」，而是看**偏离我方标准多远、还能接受到什么程度**。
与 `contract-review-layers`（宏观/中观/微观）并用：分层负责找问题，本 Skill 负责定处置档位。

来源方法学：Anthropic 商业合同插件的 playbook（标准条款 / 可接受回退 / 永不接受）结构，Apache-2.0；
本文件为按中国合同实务独立重写，未复制其文案。

## 先定两件事（缺则先问，不要猜）

1. **己方纸还是对方纸**：我方模板 vs 对方模板。同一句话在两种纸上的档位不同。
   - 己方纸：偏离我方模板即需说明；口径从严。
   - 对方纸：以「能否接受」为主，重点看我方必须争取的底线项。
2. **我方立场**：委托方是谁。立场不明时不得给出「可签」结论，只能给条件式结论。

交办里已写明的（如「我方是买方」「对方模板」）直接用，不重复问。

## 三档处置

每个实质条款落到三档之一，并写清**依据**：

| 档位           | 含义                                         | 必须给出                             |
| -------------- | -------------------------------------------- | ------------------------------------ |
| **标准**       | 与我方口径一致，或更有利                     | 一句话确认即可，不必展开             |
| **可接受回退** | 偏离但可承受；需交换或提示                   | 回退边界（最低可接受到哪）+ 建议措辞 |
| **永不接受**   | 触碰底线：效力风险、无限责任、放弃法定权利等 | 逐条列出 + 改法 + 不接受的后果       |

「永不接受」不得滥用：只有能说清法律或商业后果的才归入此档。

## 底线项（对方纸上优先扫这几处）

1. 责任上限与责任排除是否对等；一方无限责任而另一方封顶。
2. 争议解决与管辖：是否单方指定、是否与履行地明显不符；或裁或诉须二选一。
3. 解除与终止：对方是否保留任意解除而我方没有对等权利。
4. 知识产权与数据：是否构成权属转让或超范围授权。
5. 付款与验收：验收是否由对方单方决定、付款是否倒挂。
6. 保密与竞业：期限、范围是否超出必要。

以上是扫描顺序，不是检查表清单；没有的条款不写「无此项」。

## 交件口径

- 交件仍是**审查意见**（或按交办钉选的 Word 改稿），不因本 Skill 改成别的东西。
- 每个「可接受回退」「永不接受」都必须有**具体改法**（改哪几个字或加哪一句）。没有改法的不算完成。
- 谈判优先级与 `contract-review-layers` 的 P0/P1/P2 对齐：永不接受 ⇒ P0；可接受回退 ⇒ P1/P2。
- 事实缺口不空转：已审部分照常给档位；缺失关键事实的条款写「结论待定，缺××」，其余继续。
- 法条能核则核现行文本；核不到写【待核实】。
- 三条里一条都不满足（立场、纸别、底线后果都说不清）时，交「需澄清清单 + 已知之处的档位」，不要硬给可签结论。
