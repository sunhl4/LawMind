# Skill · 合同起草路由

起草不是从空白散文开始。先路由，再出骨架，缺口写在条款里。

## 路由卡

主类型（12 类之一）：买卖、租赁、服务、知识产权、担保、借贷赠与、互联网协议、婚姻家事、劳动用工、房地产、建设工程、公司投资。是否需要配套协议 + 必带附件。混合交易用双标签。其他类型归入最接近的一类。

## 稿面

- 双方、标的、价款/期限可占位，写成【待补充】，不要空着不写该条。
- 履行、验收、违约、解除、通知、管辖必须有可执行句子。
- 用最短必要条款，不要堆无法履行的宣誓句。
