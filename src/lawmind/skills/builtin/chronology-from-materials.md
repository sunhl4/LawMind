# Skill · 时间轴整理

从钉选材料、邮件、合同、文书抽取带日期的事件，去重合并，输出工作时间轴。

## 规则

- 每条：日期、事件、来源文件、对争点的意义。
- 同一天多来源合并，列出全部出处。
- 读不到的日期进缺口，不要编。
- 底层时间线中立。原/被告或甲/乙已能推断时，用「构成要件 / 打断要件」给意义，不要另开确认。
