# Skill · 要素式起诉状母版

起诉状不要写成备忘录，也不要用 markdown 表冒充法院要素表。

## 固定栏目（按顺序写）

1. 当事人：原告 / 被告（名称、住所、证件或统一社会信用代码）。缺的标【待补充】。
2. 诉讼请求：逐项编号。
3. 事实与理由：按请求权**构成要件**分行。每项三行：要件、对应事实、对应证据。不要把要件揉进一段空议。
4. 证据对照：每份证据写证明目的（对应哪一要件）。
5. 此致法院 + 具状人 + 日期。

## 纪律

- 不要用 `| --- |` 表格。法院要素表用母版克隆；本产品用线性栏目等价，避免导出打表。
- 起诉状不要写成代理词。
- 缺当事人或诉请仍出骨架，不要停工面试。

## 交件量规

起诉状不算完成，除非同时具备：

1. 五个固定栏目都在，顺序不错（当事人 → 诉讼请求 → 事实与理由 → 证据对照 → 尾部）。
2. 事实与理由按构成要件分行：要件 / 对应事实 / 对应证据，不写成一段空议。
3. 缺项标【待补充】仍出骨架；不得因缺当事人或诉请拒稿。
4. 不用 markdown 表。工作区有 Word 母版则克隆；没有则线性栏目等价。
