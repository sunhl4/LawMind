# Skill · 要素式起诉状母版

起诉状不要写成备忘录，也不要用 markdown 表冒充法院要素表。  
保全申请要点、执行异议申请等**诉请类要点**同样必须出现「当事人 / 管辖 / 诉讼请求」三节标题原文。

## 固定栏目（按顺序写）

1. 当事人：原告 / 被告（或申请人 / 被申请人；名称、住所、证件或统一社会信用代码）。缺的标【待补充】。节标题必须写「当事人」。
2. 管辖：受理法院或执行法院；材料不足写【待核实】。节标题必须写「管辖」。
3. 诉讼请求：逐项编号（保全类写请求事项，但标题仍用「诉讼请求」或「请求事项」）。
4. 事实与理由：按请求权**构成要件**分行。每项三行：要件、对应事实、对应证据。不要把要件揉进一段空议。
5. 证据对照：每份证据写证明目的（对应哪一要件）。
6. 此致法院 + 具状人 + 日期（要点稿可省略尾部格式，但前三节不可省）。

## 纪律

- 不要用 `| --- |` 表格。法院要素表用母版克隆；本产品用线性栏目等价，避免导出打表。
- 起诉状不要写成代理词。
- 缺当事人或诉请仍出骨架，不要停工面试。
- 禁止只用「申请人／被申请人」冒充「当事人」节名；可在「当事人」节内再写申请人/被申请人。

## 交件量规

起诉状 / 诉请类要点不算完成，除非同时具备：

1. 「当事人」「管辖」「诉讼请求」（或「请求事项」）三节标题原文都在。
2. 事实与理由按构成要件分行：要件 / 对应事实 / 对应证据，不写成一段空议（纯要点稿可从简，但仍须有前三节）。
3. 缺项标【待补充】仍出骨架；不得因缺当事人或诉请拒稿。
4. 不用 markdown 表。工作区有 Word 母版则克隆；没有则线性栏目等价。
