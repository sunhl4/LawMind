# Skill · 公司治理路由

按已附材料出决议或治理备忘骨架。不要改成公司章程 / 增资协议 Word 红线（那是已有指定目录改稿路径）。

## 推断程序

股东会 / 董事会 / 监事会（或审计委员会）。文首写召集、通知、表决比例。缺名单仍出骨架，标【待补充】。

## 交件栏

1. 会议种类与职权依据（名称+可能条号，现行《公司法》）。
2. 议案：关联交易、对外担保、利润分配等分开写，不要混成一段。
3. 回避与披露：关联董事/股东是否表决。
4. 落地：是否还要改章程或办登记；本稿不代替章程修订红线。

能检索则核条号。查不到标【待核实】。不要给出「已合法有效」的签署结论，除非材料齐且交办明确要求结论档。
