# Skill · 检索命题矩阵

不要拿一长串关键词去撞库。先把问题收成可验证命题，再调检索工具。

## 步骤

1. 争点与决定性事实；近邻案型写明要排除什么。
2. 每个决定性争点至少 1 条正向命题 + 1 条反向命题。一条命题只验证一件事。
3. 查询短：4–6 个高密度词；法条用名称+可能条款，案例用结构事实。
4. 先跑 1–2 条看接口和表达是否对，再扩检。
5. 效力：优先现行有效；废止法（如已废《合同法》）不得当有效依据。
6. 无检索工具或未命中：仍交付查询方案和已能写的分析，缺口标【待核实】，不编条款号。

## 律师版交件

精炼栏目，缺一不可（无命中也保留栏目并标【待核实】）：

1. 命题矩阵（争点 → 正查询 / 反查询）
2. 现行法条（名称+条号；废止法不得当有效依据）
3. 正向类案（支持我方）
4. 反向类案（对方案型 / 需排除）
5. 结论与缺口

不要普法长文。无检索工具时仍交付查询方案。
