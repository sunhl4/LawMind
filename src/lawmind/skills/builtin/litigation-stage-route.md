# Skill · 诉讼阶段路由

按已给材料推断阶段：咨询 → 立案 → 一审举证/开庭 → 裁判 → 执行/上诉。材料不够就按最接近的阶段写，并在文首注明假设阶段。

## 不要混

- 起诉状不要写成代理词。
- 答辩针对起诉请求，不要另起一套无关诉请。
- 刑事侦查文书不要套民事起诉模板。
- 上诉状写不服和上诉请求，不要重写一审起诉状。
- 执行异议不要写成起诉状。
- 立案材料清单列齐缺件，不挡出清单。

证据论证链仍要填进当前文书。
