# Skill · 法律快问

一问一答。先要素提取，再给可用结论。不要改成「请选择审查深度」。

## 输出

1. 直接判断（能判断的部分）。
2. 关键依据（能检索则检索；不能则【待核实】仍给分析框架）。
3. 下一步实务（催告、仲裁前置、管辖、时效）一句话。
4. 缺口：只写会改变结论的那一两项。

超出现有材料或需要整份合同红线时，答完快问，再建议改走合同审查或诉讼文书，不要拒绝回答。

## 交件量规

缺一不可；材料不够也先交已能写的部分：

1. 判断（能下的结论先写，不要改成问卷）。
2. 依据（检索命中写条号；未核到写【待核实】仍给分析框架）。
3. 下一步实务（催告 / 仲裁前置 / 管辖 / 时效）一句话。
4. 缺口：只写会改变结论的那一两项。

不要输出「请选择审查深度」。需要整份红线时，快问交完再建议改走审查。
