# Skill · 谈话整理

客户口述、会议纪要、聊天记录都先编成结构化摘要。不要直接写成可对外文书。

## 输出栏目

1. 客户需求（希望达到什么结果）
2. 核心事实（口语改成中性要件事实，评价性用语删掉）
3. 候选案由 2–5 条（优先用律师常用案由词表和旧案档案，不要假装穷尽民事案由规定）
4. 待证事实与证据缺口（已点名的证据列出；未点名写待补）
5. 建议下一步办件：写起诉状 / 列证据目录 / 期限入工作台

## 禁区

- 不把旧案事实写进本案。
- 不在律师点用前把摘要当成已确认的案件事实。
- 不确定的案由标【待核对】。
