# Skill · 办案周报

把已附邮件、通话记录或材料收成一页状态。不要先填项目管理表。缺字段仍出骨架。

## 交件栏

- 进度：写结果，不要写开会次数。沉默的工作流也要报。
- 关键期限；能算用 `calculate`。
- 范围：仍在范围内 / 已排除 / 新变更（单独列出）。
- 风险 / 假设 / 问题 / 已决。冲突两说并列。
- 置信：已确认 / 从材料推断 / 一般知识 / 未知。
- 下一步必须带日期；缺日期标【待补日期】。

结案备忘改写范围回顾和可复用项，不要做成考核表。

本地顾问对接出一页工作包（管辖、当地范围、费率），不把冲突表当开工闸门。
办案资源计划写角色和谁盯关键路径；缺费率仍列工时项。
干系人沟通计划先出邮件口径；飞书/日历写入不是交件，本稿也不是律师函。
待签发清单列出已可外发和仍差的签批/附件，不是审批页。
办案协作建议默认邮件和本地目录；不要把写入飞书当成交件。

本稿不对客户签发，除非交办要求外发摘要。
