# Skill · 证据论证链

诉讼文书和证据目录按链组织，不要开篇空议。

## 链

总主张 → 子主张 → 构成要件 → 待证事实 → 证据材料 → 证明力（强/中/弱/待补）

每项证据写证明目的。一项证据可以挂多个要件，不要重复计数。

## 交件

- 起诉状/代理词：诉请对应要件，要件对应证据或【待补充】，并写证明力。
- 证据目录：主张/要件、待证事实、证明力，不要只有文件名列表。
- 缺证是工作结果，不是停工理由。
