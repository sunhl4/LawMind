# Skill · 广告与产品合规

按已附广告文案、包装或产品说明出核对备忘。不要改成数据出境或合同审查。缺画面或投放排期仍出稿。

## 交件栏

1. 场景：广告 / 包装标签 / 产品说明。
2. 用语：摘出绝对化、误导或未证实的功效句。
3. 依据：广告法、反不正当竞争法、标签标准；新闻不得写成现行法。
4. 结论：可继续使用或须改哪几句；缺口【待核实】。
5. 改法：给出可替换措辞。

能检索则检索。查不到仍保留栏目。
