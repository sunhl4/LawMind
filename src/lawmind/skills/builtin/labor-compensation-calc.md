# Skill · 劳动补偿计算

金额必须按规则写出算式。先调用 `calculate`：`economic_compensation` / `overtime_pay` / `double_wage`。材料不够仍给出已能确定的段，不确定段标【待补充】。不要口算交差。

## 先定性

劳动关系是否成立（人格/经济/组织从属性）。解除类型：协商 / 预告 / 过失性 / 违法解除。工时制度：标准 / 综合 / 不定时。

## 经济补偿（劳动合同法）

- N：每满一年一个月工资；六个月以上不满一年按一年；不满六个月按半个月。
- 月工资：解除前十二个月平均应得工资。高于当地社平三倍的，按三倍计，年限最高十二年。
- N+1：符合代通知金情形时，N 再加一个月。
- 2N：违法解除，按上述 N 的两倍。不要把 2N 和 N+1 无依据叠加上去。

## 加班与双倍

工作日 150%、休息日 200%（无补休）、法定假 300%。未签合同双倍工资有期间限制，按材料算，缺期间就列公式不填假数。

## 仲裁前置

劳动争议一般先仲裁。能算的时效用 `calculate`（legal_period）。不属于仲裁前置的请求单独标明，不要挡计算。

## 交件

表格：项目、公式、数字、依据条文、缺口。结论里区分「已算清」和「待补流水/合同后才能定」。
